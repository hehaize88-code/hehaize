# Wenn der Produktlink nicht funktioniert: Linkimport oder manuelle Bestellung bei CNShopper?
Sie fügen einen Verkäuferlink in einen Einkaufsagent ein und der Artikel wird nicht wie erwartet angezeigt. Manchmal ist die Quellseite verschwunden. Manchmal existiert die Seite, aber der Agent kann eine wichtige Option nicht erfassen. Manchmal wurde der falsche Link kopiert. Eine manuelle Bestellung ist nützlich, wenn ein Käufer anhand der von Ihnen bereitgestellten Informationen ein echtes Angebot identifizieren kann. Es repariert kein Angebot, das Sie nicht selbst identifizieren können.

## Überprüfen Sie, ob es sich bei dem Link um eine Produktseite handelt
Öffnen Sie den ursprünglichen Marktplatz-Link und überprüfen Sie sein Ziel. Zeigt es ein Produkt mit einem Verkäufer und Optionen? Eine Suchergebnisseite, die Homepage des Verkäufers, ein Werbealbum oder ein Foto in sozialen Medien können den Artikel enthalten, ohne dass ein kaufendes Angebot identifiziert wird. Kopieren Sie die Produktseite und nicht die Seite, die Sie zu ihr geführt hat. Behalten Sie den Marktplatznamen und die Artikelkennung bei, falls diese sichtbar sind.

Stellen Sie sich vor, Sie speichern einen Screenshot eines Schreibtisch-Organizers aus der Galerie eines Verkäufers. Wenn Sie auf die freigegebene Adresse tippen, wird die gesamte Briefpapierkollektion des Shops geöffnet. Sie können das Produkt in einem Bild erkennen, aber der Käufer muss immer noch wissen, welches Angebot und welche Option er kaufen soll. Finden Sie den einzelnen Veranstalter oder fragen Sie den Verkäufer nach seinem Link. Eine manuelle Notiz mit der Aufschrift „dritter Artikel im Bild“ kann unbrauchbar werden, wenn der Verkäufer die Anzeigereihenfolge ändert.

## Verstehen, was ein erfolgreicher Import festlegen sollte
Die Bestellanleitung von CNShopper beschreibt, wie Sie mit einem Marktplatzlink beginnen und den Artikel, die Option, die Menge und die Kosten vor dem Kauf bestätigen. Verwenden Sie diese Sequenz, um den Import zu testen. Passen Sie den Verkäufer, die Artikelidentität, die Variantenauswahl und den Preis an die gewünschte Option an. Ein erfolgreiches Laden der Seite ist nur das erste Ergebnis. Wenn die günstigste Option ein Zubehör ist, während Sie das komplette Produkt möchten, entscheidet der Preis neben dem ersten Bild nicht über den Kauf.

Versuchen Sie, die vollständige Auswahl zu treffen, bevor Sie entscheiden, dass etwas fehlt. Eine Größenliste kann von der Farbe abhängen, die Sie zuerst gewählt haben. Ein Bundle kann einen anderen Selektor für seinen Inhalt freigeben. Nachdem alle Felder eingestellt sind, lesen Sie die abschließende Zusammenfassung zusammen. Wenn es Ihren beabsichtigten Artikel getreu beschreibt, bietet eine normale linkbasierte Bestellung eine einfachere Aufzeichnung als die manuelle Eingabe der gleichen Informationen.

## Ein Importproblem von einem Verkäuferproblem unterscheiden
Kehren Sie zur Verkäuferseite zurück und prüfen Sie, ob die Kombination dort vorhanden ist. Wenn der Verkäufer grün in Medium anbietet, aber die importierte Seite diese Option weglässt, haben Sie eine identifizierbare Diskrepanz, nach der Sie fragen können. Wenn der Verkäufer überhaupt keine grünen Listen mehr hat, kann eine manuelle Bestellung nicht feststellen, dass der Verkäufer eine hat. Fragen Sie nach der Verfügbarkeit, bevor Sie die Zahlung autorisieren oder eine andere Farbe auswählen.

Bei einem bearbeiteten Eintrag behalten Sie das Datum Ihrer Beweise bei. Ein Screenshot vom letzten Monat erklärt vielleicht, wonach Sie gesucht haben, beschreibt aber möglicherweise nicht mehr das aktuelle Angebot. Speichern Sie die aktuelle Verkäuferseite neben der älteren Referenz und identifizieren Sie den Unterschied. Zum Beispiel: „Die ältere Seite zeigte ein abnehmbares Tablett an; die heutige Option nennt nur den Organisatorkörper.“ Eine klare Frage zum Tablett ist nützlicher, als einen alten Link erneut einzureichen und zu hoffen, dass er das frühere Bündel wiederherstellt.

## Erstellen einer manuellen Anfrage aus positiven Bezeichnern
Wenn für Ihren Fall ein manueller oder DIY-Kauf angeboten wird, geben Sie die Verkäufer-URL, den Produktnamen, den genauen ursprünglichen Optionentext, die gewünschte Farbe, Größe, Einheit und Menge an. Fügen Sie den für diese Auswahl angezeigten Preis hinzu und geben Sie die Währung an. Fügen Sie einen Screenshot der ausgewählten Option bei, wenn sie Mehrdeutigkeiten auflöst. Die Anfrage sollte es dem Käufer ermöglichen, das Angebot zu finden, auch wenn sich die Übersetzung seines Titels ändert.

Trenne Anweisungen von Fragen. „Kaufen Sie den grauen 36-Zentimeter-Organizer mit herausnehmbarem Tablett, Menge eins, wenn das Tablett in dieser Option enthalten ist“ ist eine bedingte Anweisung. „Kann der Verkäufer bestätigen, dass das Tablett enthalten ist?“ ist die Frage, die zuerst beantwortet werden muss. Wenn die Bedingung für Sie wichtig ist, geben Sie an, ob Sie den Kauf bis zum Erhalt einer Antwort zurückhalten möchten. Vermeiden Sie es, eine billigere Option zu wählen und den Namen eines anderen Produkts in die Notizen zu schreiben.

## Behalten Sie Ersetzungen unter Kontrolle
Eine manuelle Anfrage wird manchmal mehrdeutig, wenn ein Verkäufer die genaue Auswahl nicht liefern kann. Entscheiden Sie im Voraus, welche Unterschiede akzeptabel sind. Einige Käufer würden einen anderen Umkarton akzeptieren, aber auf den gleichen Abmessungen bestehen. Andere benötigen einen exakten Farbton für ein passendes Set. Geben Sie die Anforderung an und was der Käufer tun soll, wenn sie nicht erfüllt werden kann.

Ein Beispiel ist ein Paar passender Aufbewahrungsboxen. Der in Ihrer Referenz gezeigte Blauton passt zu einem vorhandenen Regal, während ein Verkäufer auch Teal anbietet. Die beiden Optionenbilder sehen auf einem Telefon ähnlich aus, aber die Verkäufernamen unterscheiden sich. Wenn die Farbe den Kauf bestimmt, schreiben Sie „Bitte fragen Sie, bevor Sie das ausgewählte Blau durch einen anderen Farbton ersetzen.“ Schreiben Sie nicht „Etwas Ähnliches ist in Ordnung“, nur um das Formular auszufüllen, es sei denn, das ist wirklich Ihre Entscheidung.

## Überprüfen Sie die kommerziellen Details vor der Zahlung
Bei einer manuellen Auswahl vergleichen Sie den bestätigten Produktpreis, die Stückzahl und die nationale Lieferung mit dem ursprünglichen Angebot des Verkäufers. Wenn sich die Zahl ändert, beschreiben Sie, warum. Er kann eine höhere Variante, eine Mindestbestellmenge, den Versand vom Verkäufer oder einen neueren Preis widerspiegeln. Eine Erklärung, die die Bestellung mit dem tatsächlichen Angebot in Einklang bringt, ermöglicht Ihnen eine Kaufentscheidung zu treffen. Ein vermuteter Grund tut es nicht.

Betrachte eine aufgeführte Menge von 30 für einen Ersatzdeckel und 110 für den kompletten Behälter. Wenn Sie den vollen Behälter anfordern, ist die Differenz kein unerklärlicher Aufpreis. Umgekehrt, wenn der bestätigte Betrag 110 für eine Option nur mit Deckel ist, muss diese Diskrepanz geklärt werden. Verwenden Sie illustrative Abbildungen nur, um die Unterscheidung zu verstehen. Ihre tatsächliche Bestellung sollte den aktuellen Betrag und die aktuelle Währung des Verkäufers beibehalten und das internationale Paketbudget sollte von der Kaufzahlung getrennt bleiben.

## Entscheiden Sie, wann Sie aufhören und woanders suchen
Wenn weder das Angebot noch der Verkäufer die gewünschte Option identifizieren können, pausieren Sie, anstatt die Unsicherheit in eine Bestellung umzuwandeln. Ein manuelles Formular kann eine Absicht kommunizieren; es kann keine fehlenden Nachweise über die Verfügbarkeit, die Verkaufsberechtigung oder genau das, was enthalten ist, liefern. Wenn Sie einen anderen Verkäufer wählen, starten Sie einen neuen Vergleich. Übertragen Sie nicht die Größentabelle des vorherigen Verkäufers, erwartetes Zubehör oder Fotos, als ob sie den Ersatz beschreiben.

In einigen Fällen kehrt ein direkter Quelllink zurück, nachdem ein Verkäufer die Seite aktualisiert oder eine korrigierte Adresse gesendet hat. Überprüfen Sie den neuen Link erneut anhand Ihrer Anforderungen und entscheiden Sie, ob der Linkimport nun ein vollständiges Angebot liefert. Wenn eine frühere manuelle Anfrage noch offen ist, identifizieren Sie sie und vermeiden Sie es, zwei Käufern zu sagen, dass sie dieselbe Einheit kaufen sollen. Bestätigen Sie, welche Anfrage bearbeitet wird, bevor Sie zweimal bezahlen oder den falschen Datensatz löschen.

## Führen Sie die Auswahl durch die Lagerüberprüfung
Sobald die Bestellung bestätigt ist, bewahren Sie Ihre endgültige Spezifikation mit der Bestellreferenz auf. Verwenden Sie diese Spezifikation beim Wareneingang, um den tatsächlichen Artikel zu überprüfen. Ein Foto, das einen grauen Ordner zeigt, kann seine Farbe und allgemeine Form feststellen, während ein Blick auf den Deckel und das Tablett zusammengelegt notwendig sein kann, um das Bündel zu bestätigen. Fragen Sie nach dem ungelösten Feature, während das Element noch zur Prüfung zugänglich ist.

Der praktische Test ist, ob Ihre Bestellung von jemandem gelesen werden kann, der die ursprüngliche Shortlist nie gesehen hat. Sie sollten in der Lage sein, den Verkäufer zu nennen, das Produkt zu identifizieren, die Option zu reproduzieren, die Einheiten zu zählen und zu sagen, was zu tun ist, wenn ein Schlüsselmerkmal nicht verfügbar ist. Wenn der Link-Import diese Informationen liefert, verwenden Sie sie. Wenn nur eine manuelle Anfrage es genau tragen kann, geben Sie dem Käufer eine Spezifikation, die er überprüfen kann. Der Workflow sollte der Qualität des tatsächlich gefundenen Angebots folgen.

Wenn das ursprüngliche Angebot später korrekt importiert wird, überprüfen Sie Ihren Kaufverlauf, bevor Sie von vorne beginnen. Eine manuell übermittelte Anfrage und eine neu importierte Warenkorbzeile können sich beide auf dasselbe gewünschte Gerät beziehen. Markieren Sie, welche Anforderung fortgesetzt und die andere über die verfügbaren Steuerelemente der Bestellung gelöst werden soll.
