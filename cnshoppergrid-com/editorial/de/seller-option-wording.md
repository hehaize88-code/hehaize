# Die genaue Variantenbezeichnung des Verkäufers in einer CNShopper-Bestellung festhalten
Zwei Optionen können nach der Übersetzung identisch aussehen, obwohl der Verkäufer sie als verschiedene Produkte behandelt. Ein Code, ein Suffix oder eine kleine Zeichnung im Selektor können Größensysteme, Bündelinhalte, Revisionen oder Oberflächen unterscheiden. Bewahren Sie genug von der ursprünglichen Auswahl auf, damit ein Käufer Ihre Auswahl reproduzieren kann. Eine lesbare englische Beschreibung hilft, Ihre Absicht zu erklären; der genaue Wortlaut des Verkäufers hilft, die Steuerung zu identifizieren, die es tatsächlich bestellt.

## Erfassen Sie die Auswahl anstelle des Produkttitels
Ein Produkttitel beschreibt im Allgemeinen die Familie der Artikel. Die Option identifiziert, welches Mitglied dieser Familie Sie möchten. Öffnen Sie die Verkäuferseite, nehmen Sie die komplette Auswahl vor und speichern Sie die genaue Formulierung neben dem Produktlink. Wenn die Option ein Bild mit wenig Text ist, speichern Sie einen Screenshot, der zeigt, welches Farbfeld hervorgehoben ist und wie es sich auf das Produkt bezieht.

Denken Sie an ein Notizbuch-Angebot mit dem Titel „A5-Reisetagebuch, mehrfarbig.“ Der Titel gibt fast keine Informationen darüber, ob die ausgewählten Seiten liniert, gepunktet oder leer sind. Ein Thumbnail, das eine geschlossene marineblaue Abdeckung zeigt, kann alle drei darstellen. Wenn der Selektor einen Code wie B2 angibt, behalten Sie diesen Code genau so bei, wie Sie ihn gelesen haben. Gehen Sie nicht davon aus, dass B2 leer bedeutet, es sei denn, der eigene Optionsschlüssel des Verkäufers stellt die Verbindung her.

## Bewahren Sie das Original und Ihre Interpretation in separaten Feldern auf
Wenn Sie eine Verkäuferoption übersetzen, halten Sie die Quellphrase neben Ihrer Übersetzung sichtbar. Ein Käufer kann dann prüfen, ob Ihre verständliche Interpretation mit dem tatsächlichen Button übereinstimmt. Dies ermöglicht es Ihnen auch, eine Interpretation später zu korrigieren, ohne den einzigen zuverlässigen Nachweis der Auswahl zu verlieren. Kopieren Sie bedeutende Satzzeichen, Modellsuffixe und Einheiten genau, wo dies möglich ist.

Wenn auf einem übersetzten Etikett „groß“ steht, während die Ausgangsoption mit einem numerischen Code endet, vergleichen Sie diesen Code mit der Größentabelle des Verkäufers. Der Code könnte eine Kleidungsstückgröße, ein Modelljahr, eine Kapazität oder eine Packungszahl angeben. Andere Verkäufer können das gleiche englische Wort unterschiedlich verwenden. Ersetzen Sie einen Code nicht stillschweigend durch eine angenommene Bedeutung; geben Sie die genaue Auswahl an und markieren Sie das Attribut, das noch bestätigt werden muss.

## Trennen Sie die Dinge, die Sie zusammen auswählen
Beschreiben Sie die unabhängigen Selektordimensionen. Ein Shirt-Angebot kann eine Zeile für die Farbe, eine andere für die Größe und eine weitere für die Passform verwenden. Ein Schreibtischprodukt kann separate Selektoren für Breite, Oberfläche und ob Befestigungsmaterial enthalten ist haben. Das Kopieren eines einzelnen kombinierten Farbnamens ohne die anderen Steuerelemente hinterlässt eine unvollständige Spezifikation.

Ein Beispielhinweis für ein Regal könnte lauten: „Ausgewählte Oberfläche im beigefügten Quelltext als aschegrau dargestellt; Breitenoption 60 cm; Montagesatz enthalten; Menge eins.“ Wenn der Verkäufer 60 Zentimeter als innere Nutzbreite oder als gesamte Außenbreite anbietet, identifizieren Sie, welche Sie benötigen, und bitten Sie um Bestätigung. Die Notiz sollte beschreiben, was Sie geklickt haben und was unbekannt bleibt. Eine technisch präzise Zahl nützt wenig, wenn sie die falsche Messung darstellt.

## Überprüfen Sie die Option nach dem Ändern eines anderen Selektors erneut
Einige Kombinationen hängen von einer früheren Wahl ab. Durch Ändern der Oberfläche kann eine Größe zurückgesetzt, das Hauptbild ersetzt oder ein Bündel ausgeblendet werden. Nachdem Sie das letzte Feld ausgewählt haben, lesen Sie alle aktiven Optionen aus der abschließenden Zusammenfassung erneut durch. Speichern Sie den Screenshot an dieser Stelle. Ein Bild, das zwei Bildschirme früher aufgenommen wurde, zeigt möglicherweise eine Kombination, die nicht mehr ausgewählt ist.

Angenommen, Sie entscheiden sich zunächst für ein weißes Doppelschicht-Federmäppchen und wechseln dann zu Navy. Der Verkäufer bietet marine nur in der einlagigen Ausführung an. Wenn die Schnittstelle den zweiten Selektor zurücksetzt, könnte deine letzte Wahl marineblaue Einschicht sein, obwohl du dich daran erinnerst, eine Minute zuvor auf Doppelschicht zu tippen. Vergleichen Sie die angezeigte Zwischensumme und Optionszusammenfassung mit den schriftlichen Anforderungen. Wenn die genaue Kombination nicht reproduziert werden kann, fragen Sie den Verkäufer, was verfügbar ist, bevor Sie eine manuelle Anfrage senden.

## Ähnliche Labels mit einem Vergleichspaar unterscheiden
Wenn zwei Optionen ähnlich aussehen, erfassen Sie sie nebeneinander in Ihren Notizen mit ihren Unterschieden. Man könnte „mit Riemen“ zeigen, ein anderes „Ersatzriemen.“ Eine Fehlübersetzung, die beide auf „Riemen“ reduziert, könnte einen Taschenkauf in einen Zubehörkauf verwandeln. Vergleichen Sie die Einheit, die Preisdifferenz, die enthaltenen Stücke und die Beschreibung der Verkäuferoption, bevor Sie die beabsichtigte Auswahl interpretieren.

Bei einer echten Bestellung schreiben Sie die abgelehnte Alternative sowie die gewählte Option auf, wenn Verwirrung wahrscheinlich ist. Ein nützlicher Satz ist: „Ich möchte die komplette grüne Tasche mit Schulterriemen. Wählen Sie nicht den Ersatzschultergurt, der unter demselben Angebot angeboten wird.“ Diese Anweisung nennt das tatsächliche Risiko. Ein vager Satz wie „wählen Sie die richtige Version“ lässt den Käufer mit genau der Mehrdeutigkeit zurück, die Sie entfernen wollten.

## Die bestätigte Bestellung mit dem Quellnachweis abgleichen
CNShoppers Bestellleitfaden fordert Käufer auf, vor dem Kauf Größe, Farbe, Menge und relevante Verkäuferhinweise anzugeben. Wenn eine Bestätigung verfügbar ist, vergleichen Sie die endgültige Option mit der gespeicherten Verkäuferauswahl. Tun Sie dies, solange eine Diskrepanz noch abgefragt werden kann. Wenn die Bestätigung eine lange Option abkürzt, bitten Sie um Klärung des fehlenden Suffixes oder der enthaltenen Komponente, anstatt einen allgemeinen passenden Titel zu akzeptieren.

Wenn ein Verkäufer dasselbe Produkt unter einer neuen Artikelnummer neu einstellt, behandeln Sie die neue Seite als neues Angebot. Behalten Sie die Originalaufzeichnung und vergleichen Sie beide. Beschreibt der gleiche Optionenname immer noch die gleichen Abmessungen und Teile? Werden die Fotos aus einer früheren Version wiederverwendet? Eine aus dem alten Angebot eingefügte Notiz ist ein Ausgangspunkt für den Vergleich. Es wird nicht festgelegt, dass das neue Verkäufermenü Codes auf die gleiche Weise zuordnet.

## Verwenden Sie Lagerfotos, um die Anforderung zu testen
Fragen Sie bei der Aufnahme, welcher Teil der Option tatsächlich visuell geprüft werden kann. Farbe, Druckgröße, sichtbare Konstruktion und enthaltenen Teile können beobachtet werden; Materialzusammensetzung oder Langlebigkeit benötigen in der Regel andere Nachweise. Ein Foto einer geschlossenen Box kann ein Optionsetikett zeigen, ohne nachzuweisen, dass sich jede beworbene Komponente darin befindet. Stellen Sie Ihre Frage in Bezug auf das, was eine Lagerprüfung vernünftigerweise feststellen kann.

Für das Beispiel des Federmäppchens könnte ein direktes Außenfoto Marinefarbe zeigen, aber die Anzahl der Schichten unklar lassen. Fordern Sie eine Ansicht der offenen Fächer an, die mit dem richtigen Lagerdatensatz für einen einzelnen Artikel verknüpft sind, abhängig vom verfügbaren Service. Vergleichen Sie es mit der bestätigten Bestellung und Ihrer gespeicherten Quellenauswahl. Wenn die erhaltene Einheit die Einschicht-Option ist, liefern die ursprüngliche Formulierung und der Screenshot eine viel stärkere Erklärung als eine spätere Behauptung, dass Sie sich daran erinnern, etwas anderes ausgewählt zu haben.

## Führen Sie eine geordnete Aufzeichnung, wenn der Verkäufer antwortet
Wenn Sie eine Klärung erhalten, speichern Sie die Antwort des Verkäufers mit dem Datum und dem spezifischen Angebot. Notieren Sie, ob es die bestehende Option bestätigt oder einen Ersatz vorschlägt. Beispielsweise unterscheidet sich die Bestätigung, dass „Code C das Montagekit enthält“, von einem Angebot, das Kit gegen einen zusätzlichen Betrag separat hinzuzufügen. Aktualisieren Sie die schriftliche Spezifikation, wenn die vorgeschlagene Änderung akzeptiert wird.

Wenn die Transaktion abgeschlossen ist, behalten Sie die ursprüngliche Option, die akzeptierte Zusammenfassung und den Nachweis, mit dem Sie den Lagerartikel genehmigt haben. Wenn Sie die Tabelle Monate später erneut aufrufen, sehen Sie möglicherweise eine andere Reihenfolge der Optionen oder andere Übersetzungen. Ihre Aufzeichnung zeigt immer noch, was der Verkäufer zu diesem Zeitpunkt angeboten hat und was Sie tatsächlich in Auftrag gegeben haben. Das ist der praktische Wert der Beibehaltung der Wortwahl des Verkäufers: Sie überlebt Änderungen an der Präsentation lange genug, um Fragen zu Ihrem bestimmten Kauf zu beantworten.

Für übereinstimmende Stücke, überprüfen Sie die Option Konsistenz über mehr als ein Angebot. Ein Gehäuse und sein separater Gurt können beide als grün beschrieben werden, obwohl sie unterschiedliche Lieferantenfarbennamen oder Befestigungsbreiten tragen. Fragen Sie nach dem genauen Etikett oder Maß, das die beiden verbindet. Wenn eine passende Oberfläche unerlässlich ist, machen Sie diese Bedingung ausdrücklich, bevor Sie für einen Teil bezahlen. Zwei Etiketten, die in dasselbe englische Wort übersetzt werden, können sich immer noch auf verschiedene Oberflächen im eigenen Katalog des Verkäufers beziehen.
