# Ein Problem nach dem Kauf beim CNShopper-Kundenservice melden

Eine effektive After-Sales-Anfrage ermöglicht es einer anderen Person, den Kauf zu rekonstruieren, zu sehen, was schief gelaufen ist, und zu verstehen, welche Entscheidung Sie benötigen. Der Nachweis ändert sich je nachdem, ob sich die Ware beim Verkäufer, im Lager des Maklers oder bereits an Ihrer Adresse befindet. Die Bestell- und Hilfeseiten von CNShopper geben Kontext für diese Phasen. Überprüfen Sie die verfügbaren Optionen auf Ihrer eigenen Bestellung, bevor Sie um eine Abhilfe bitten. Verfügbarkeit, Zeitpunkt und Kosten können vom Verkäufer, dem Service und den Umständen abhängen.

## Identifizieren Sie die genaue Einkaufsposition

Öffnen Sie die ursprüngliche Bestellung und kopieren Sie den Produkttitel, den Verkäuferoptionstext, die Menge und die Zeilenreferenz. Fügen Sie die Lager- oder internationale Paketreferenz hinzu, wenn das Problem später aufgetreten ist. Eine einzige Sendung kann mehrere nahezu identische Produkte enthalten. Wenn Sie melden, dass „der schwarze falsch ist“, muss der Agent erraten, welchen Verkäufer oder Kauf Sie meinen. Schreiben Sie das unterscheidende Detail im ersten Satz, wie z. B. den schwarzen Einfachtaschen-Organizer aus der bestimmten Einkaufszeile, die Sie identifizieren.

Erläutern Sie die vereinbarte Spezifikation anhand der Aufzeichnung vom Zeitpunkt des Kaufs. Verkäufer können Fotos und Optionennamen auf einer Live-Seite ändern. Eine gespeicherte Auswahl, eine Bestätigungsnachricht oder ein datierter Screenshot können den Originaltext anzeigen. Wenn Sie spezielle Anweisungen gegeben haben, fügen Sie die Antwort des Agenten zusammen mit Ihrer eigenen Nachricht bei. Eine Aufforderung, das längere Modell zu wählen, und eine Bestätigung, dass der Verkäufer es liefern kann, sind zwei verschiedene Beweismittel. Halte ihre Rollen klar.

## Beschreiben Sie eine beobachtbare Diskrepanz

Sagen Sie, was Sie erwartet haben, was Sie sehen können und woher die Beobachtung stammt. „Die gewählte Option beinhaltet zwei Innentaschen. Das Innenfoto dieses Lagerartikels zeigt eine genähte Tasche“ gibt dem Agenten etwas zu inspizieren. „Schlechte Qualität“ kann ein Problem mit dem Aussehen, falsches Material, schlechte Verarbeitung oder eine beschädigte Sendung bedeuten. Wenn der Unterschied nicht auf einem Foto zu sehen ist, beschreiben Sie das praktische Symptom und die Bedingungen, unter denen Sie es beobachtet haben.

Ein Passformproblem benötigt einen anderen Nachweis als eine Sendung mit einer falschen Größe. Überprüfen Sie das eingenähte Etikett und wie der Verkäufer die aufgeführten Maße definiert. Ein Kleidungsstück, das sich eng anfühlt, kann genau die bestellte Größe tragen. Wenn der Verkäufer eine Kleidungsstückweite angegeben hat, zeige, welche zwei Punkte du gemessen hast und ob der Stoff gedehnt wurde. Wenn Sie nur ein Größenetikett haben, melden Sie diese Beobachtung ehrlich. Fragen Sie, ob eine andere Messung oder ein Foto verfügbar ist, wenn es helfen würde, die Unterscheidung festzustellen.

## Wählen Sie Fotos aus, die eine Frage beantworten können

Verwenden Sie ein Gesamtbild, um die Person, die den Fall überprüft, zu orientieren, und fügen Sie dann ein genaueres Bild des umstrittenen Details hinzu. Bei einer Farbabweichung fotografieren Sie sowohl das Produkt als auch das Optionenetikett, falls vorhanden. Beschreiben Sie die Beleuchtung, wenn Farbe zentral für die Entscheidung ist. Bildschirmeinstellungen, Lagerbeleuchtung und das ursprüngliche Eintragsbild können das Erscheinungsbild beeinflussen. Ein Etikett mit dem Farbcode des Verkäufers kann dem Rezensenten eine zweite Möglichkeit geben, zu identifizieren, was gesendet wurde.

Bei einer beschädigten Lieferung behalten Sie die Verpackung, während das Problem beurteilt wird. Fotografieren Sie den äußeren Zustand und den Standort des Artikels oder das Schutzmaterial, wenn Sie dies zum Zeitpunkt des Öffnens tun können. Beschreiben Sie, was Sie direkt beobachtet haben. Eine zerquetschte Ecke an einer Kiste und ein Kratzer an der Ware können beide dokumentiert werden, ohne entscheiden zu müssen, wer den Schaden verursacht hat. Wenn du den Kratzer später bemerkt hast, sag, wann du ihn gefunden hast. Dieses Detail hilft dem Reviewer, die Evidenz fair zu interpretieren.

## Stellen Sie die Anfrage mit dem Standort des Artikels in Einklang

Wenn sich der Artikel noch im Lager befindet, entscheiden Sie, ob Sie vor einem Umtausch oder einer Rücksendung weitere Informationen wünschen. Das Problem kann durch ein klareres Bild eines Etiketts oder eine Zählung der Stücke in einem Bündel gelöst werden. Geben Sie den Lagerartikel an und fragen Sie, ob die Prüfung das Öffnen versiegelter Verpackungen oder die Zahlung einer Gebühr beinhaltet. Halten Sie es aus einer Paketeinreichung heraus, während Sie sich entscheiden. Sobald der Artikel mit nicht verwandten Waren verpackt ist, erfordert die Identifizierung und Trennung möglicherweise einen anderen Prozess.

Wenn Sie den Artikel bereits in Übersee erhalten haben, beschreiben Sie die Liefer- und Öffnungsdaten so genau wie möglich. Lesen Sie die dem Paket beigefügten Serviceinformationen und fragen Sie, wo Sie die entsprechenden Dokumente einreichen können. Senden Sie keine unerwünschte internationale Rücksendung an eine Adresse, die von einem nationalen Etikett kopiert wurde. Fragen Sie nach dem autorisierten Empfänger, der erforderlichen Referenz, der Methode und wer jede Etappe bezahlen würde, bevor Sie eine Sendung arrangieren. Bewahren Sie schriftliche Anweisungen zusammen mit dem Fall auf, damit zukünftige Sendungsverfolgungen der korrekten Anfrage zugeordnet werden können.

## Fragen Sie nach einem bestimmten Mittel und seinen Bedingungen

Wählen Sie das praktische Ergebnis, das Sie benötigen. Eine zusätzliche Prüfung, der Umtausch gegen eine benannte Option, die Rückgabebewertung oder die Klärung einer Belastung erfordern jeweils eine andere Reaktion. Wenn Sie einen Umtausch anfordern, geben Sie an, was zu tun ist, wenn der Ersatz nicht verfügbar ist. Eine Farbe der zweiten Wahl, die Sie vorher beiläufig erwähnt haben, kann mit einer Autorisierung verwechselt werden. Geben Sie eine klare Anweisung, zu pausieren, wenn ein Ersatz die Größe, das Design, den Preis oder ein anderes Merkmal ändern würde, das Ihre Entscheidung beeinflusst.

Wenn es um Geld geht, fragen Sie nach dem Betrag, der Währung und den Komponenten, bevor Sie zustimmen. Eine Rückerstattung des Verkäufers, inländische Rücksendekosten, eine Servicegebühr und internationale Fracht können in verschiedenen Datensätzen erscheinen. Fragen Sie, welche Beträge der vorgeschlagene Beschluss betrifft und wo eine Gutschrift erscheinen würde. Verwenden Sie beim Vergleich des Vorschlags mit Ihrer ursprünglichen Zahlung die betroffene Zeile. Eine Zahlung, die mehrere Produkte abdeckt, ist ein unzuverlässiges Maß für die Kosten, die mit einem einzigen defekten Artikel verbunden sind.

## Setzen Sie die Beweise in eine Reihenfolge, der der Gutachter folgen kann

Beginnen Sie mit Ihrer Anfrage, identifizieren Sie dann den Artikel und geben Sie eine kurze Abfolge von Ereignissen an. Erklären Sie beispielsweise, dass Sie einen bestimmten Organizer bestellt haben, ein Lagerfoto eine andere Befestigung zeigt und Sie möchten, dass der Agent die Verkäuferoption vor dem internationalen Verpacken überprüft. Folgen Sie mit der Kaufreferenz, dem ursprünglichen Optionentext und zwei beschrifteten Bildern. Der Prüfer kann nun die Datensätze in derselben Reihenfolge prüfen, in der Sie das Problem identifiziert haben.

Fügen Sie private identifizierende Informationen nur über den offiziellen Support-Kanal bei, wenn dies erforderlich ist. Eine Paketreferenz und eine Kaufzeile bieten oft einen klareren Ausgangspunkt als ein vollständiger Screenshot Ihres Kontos, Ihres Guthabens und Ihrer Lieferadresse. Behalten Sie die Originale der Bilder, die Sie für eine Nachricht zuschneiden. Wenn der Support eine breitere Ansicht der Verpackung oder des gesamten Etiketts anfordert, können Sie die angeforderte Version über den entsprechenden Kanal freigeben, ohne den ursprünglichen Kontext zu verlieren.

## Die Antwort aufzeichnen und überprüfen, ob sie ausgeführt wurde

Speichern Sie das Datum und den Wortlaut einer vorgeschlagenen Entschließung, bevor Sie sie genehmigen. Wenn ein Umtausch angeboten wird, überprüfen Sie, ob das Angebot die Rücksendung an den Verkäufer, den Ersatzkauf und die Rücksendung an das Lager umfasst. Wenn noch Klarstellungen erforderlich sind, antworten Sie möglichst innerhalb des bestehenden Falles und führen Sie den einen Punkt auf, der eine Entscheidung verhindert. Die Wiederholung der ursprünglichen Beschwerde in einem neuen Thread kann nützliche Fotos von der Antwort trennen, die sie ausgelöst haben.

Vergleichen Sie schließlich das tatsächliche Ergebnis mit dem, was Sie genehmigt haben. Für einen Umtausch überprüfen Sie den neuen Lagerdatensatz für einen einzelnen Artikel mit der korrigierten Option. Suchen Sie für eine Rückerstattung die zugehörige Transaktion und überprüfen Sie deren Betrag und Währung anhand der Vereinbarung. Bewahren Sie für eine Versandreklamation die Paketreferenz mit der abschließenden Nachricht auf. Schließe deine Notizen mit dem, was passiert ist und was noch aussteht. Dieser letzte Vergleich erfasst Fälle, in denen ein Verkäufer eine Rücksendung akzeptiert hat, der Ersatz oder die Gutschrift jedoch noch identifiziert werden muss.

Wenn mehrere identische Einheiten erworben wurden, geben Sie an, welche Einheiten das Ergebnis umfasst. Eine Gutschrift, die für ein beschädigtes Stück angeboten wird, regelt keine separate Mengendifferenz bei demselben Kauf. Behalten Sie eine Zeile pro Problem in Ihren Notizen, auch wenn der Support beide in einem einzigen Fall behandelt. Diese kleine Unterscheidung macht den endgültigen Vergleich mit der Antwort des Agenten viel einfacher.
