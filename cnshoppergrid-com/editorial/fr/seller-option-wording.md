# Comment reprendre le libellé exact du vendeur dans une commande CNShopper
Deux options peuvent sembler identiques après la traduction, même si le vendeur les traite comme des produits différents. Un code, un suffixe ou un petit dessin dans le sélecteur peut distinguer les systèmes de tailles, les contenus de paquets, les révisions ou les finitions. Préservez suffisamment de la sélection originale pour qu'un acheteur puisse reproduire votre choix. Une description en anglais lisible aide à expliquer votre intention; le libellé exact du vendeur aide à identifier le contrôle qui le commande réellement.

## Capturez la sélection plutôt que le titre du produit
Un titre de produit décrit généralement la famille d'articles. L'option identifie le membre de cette famille que vous voulez. Ouvrez la page du vendeur, effectuez la sélection complète et enregistrez le libellé exact à côté du lien du produit. Si l'option est une image avec peu de texte, enregistrez une capture d'écran montrant quel échantillon est mis en surbrillance et comment il se rapporte au produit.

Considérons un carnet de notes intitulé « Carnet de voyage A5, plusieurs couleurs ». Le titre ne fournit presque aucune information sur le fait que les pages sélectionnées soient lignées, pointillées ou vierges. Une vignette affichant une couverture marine fermée peut représenter les trois. Si le sélecteur spécifie un code tel que B2, conservez ce code exactement avec votre lecture de celui-ci. Ne supposez pas que B2 signifie vide à moins que la clé d'option du vendeur établisse la connexion.

## Gardez l’original et votre interprétation dans des champs séparés
Lorsque vous traduisez une option de vendeur, gardez la phrase source visible à côté de votre traduction. Un acheteur peut alors vérifier si votre interprétation en langage clair correspond au bouton réel. Cela permet également de corriger une interprétation ultérieurement sans perdre le seul enregistrement fiable de la sélection. Copiez la ponctuation significative, les suffixes de modèle et les unités exactement là où c'est possible.

Si une étiquette traduite indique « large » alors que l'option source se termine par un code numérique, comparez ce code avec le tableau des tailles du vendeur. Le code peut indiquer une taille de vêtement, l'année du modèle, la capacité ou le nombre d'emballages. D'autres vendeurs peuvent utiliser le même mot anglais différemment. Ne remplacez pas silencieusement un code par une signification supposée; indiquez la sélection exacte et signalez l'attribut qui nécessite encore une confirmation.

## Séparez les choses que vous sélectionnez ensemble
Décrire les dimensions du sélecteur indépendant. Une liste de chemises peut utiliser une ligne pour la couleur, une autre pour la taille et une autre pour la coupe. Un produit de bureau peut avoir des sélecteurs distincts pour la largeur, la finition et si le matériel de montage est inclus. Copier un seul nom de couleur combiné sans les autres contrôles laisse une spécification incomplète.

Un exemple de note pour une étagère pourrait dire : « Finition sélectionnée indiquée comme gris frêne dans le texte source ci-joint; option de largeur 60 cm; kit de montage inclus; quantité un. » Si le vendeur propose 60 centimètres comme largeur intérieure utilisable ou comme largeur extérieure totale, identifiez celle dont vous avez besoin et demandez confirmation. La note doit décrire à la fois ce que vous avez cliqué et ce qui reste inconnu. Un nombre techniquement précis est de peu d'utilité s'il représente la mauvaise mesure.

## Revérifiez l'option après avoir changé un autre sélecteur
Certaines combinaisons dépendent d'un choix antérieur. La modification de la finition peut réinitialiser une taille, remplacer l'image principale ou cacher un paquet. Après avoir choisi le dernier champ, relisez toutes les options actives du résumé final. Enregistrez la capture d'écran à ce stade. Une image capturée deux écrans plus tôt peut afficher une combinaison qui n’est plus sélectionnée.

Supposons que vous choisissiez d'abord un étui à crayons blanc à double couche, puis passez au bleu marine. Le vendeur propose la marine uniquement dans la version monocouche. Si l'interface réinitialise le deuxième sélecteur, votre choix final peut être le single-layer marine même si vous vous souvenez d'avoir tapé double-layer une minute plus tôt. Comparez le sous-total et le résumé des options affichés avec les exigences écrites. Si la combinaison exacte ne peut pas être reproduite, demandez au vendeur ce qui est disponible avant de soumettre une demande manuelle.

## Distinguer les étiquettes similaires avec une paire de comparaison
Lorsque deux options se ressemblent, capturez-les côte à côte dans vos notes avec leurs différences. Une erreur de traduction qui réduit les deux à « bracelet » pourrait transformer un achat de sac en un achat d’accessoire. Comparez l'unité, la différence de prix, les pièces incluses et la description de l'option du vendeur avant d'interpréter la sélection prévue.

Pour un vrai ordre, notez l'alternative rejetée ainsi que l'option choisie si la confusion est probable. Une phrase utile est « Je veux le sac vert complet avec bandoulière. Ne sélectionnez pas la bandoulière de rechange offerte dans la même liste. » Cette instruction mentionne le risque réel. Une phrase vague telle que « choisissez la bonne version » laisse l’acheteur avec exactement l’ambiguïté que vous essayiez de supprimer.

## Faire correspondre la commande confirmée à la preuve source
Le guide de commande de CNShopper demande aux acheteurs de fournir la taille, la couleur, la quantité et les notes du vendeur pertinentes avant l'achat. Lorsqu'une confirmation est disponible, comparez son option finale avec la sélection de vendeur enregistrée. Faites-le pendant qu'un écart peut encore être interrogé. Si la confirmation abrége une option longue, demandez des éclaircissements sur le suffixe manquant ou le composant inclus plutôt que d'accepter un titre générique correspondant.

Si un vendeur réinscrit le même produit sous un nouveau numéro d'article, considérez la nouvelle page comme une nouvelle offre. Gardez l'enregistrement original et comparez les deux. Le même nom d'option décrit-il toujours les mêmes dimensions et pièces ? Les photographies sont-elles réutilisées à partir d'une version antérieure? Une note collée à partir de l'ancienne liste est un point de départ pour la comparaison. Il n'est pas établi que le nouveau menu vendeur mappe les codes de la même manière.

## Utilisez des photos d'entrepôt pour tester l'exigence
Lors de l’admission, demandez quelle partie de l’option peut être vérifiée visuellement. La couleur, la taille imprimée, la construction visible et les pièces incluses peuvent être observables; la composition du matériau ou la durabilité à long terme nécessitent généralement des preuves différentes. Une photographie d'une boîte fermée peut montrer une étiquette d'option sans prouver que chaque composant annoncé est à l'intérieur. Cadrez votre question autour de ce qu'une vérification d'entrepôt peut raisonnablement établir.

Pour l’exemple de la trousse à crayons, une photo extérieure directe pourrait montrer la marine, mais laisser le nombre de couches imprécis. Demandez une vue des compartiments ouverts liés au bon enregistrement d'entrepôt pour un article individuel, sous réserve du service disponible. Comparez-le avec la commande confirmée et votre sélection de source enregistrée. Si l'unité reçue est l'option monocouche, le libellé original et la capture d'écran fournissent une explication beaucoup plus forte qu'une affirmation ultérieure selon laquelle vous vous souvenez avoir sélectionné autre chose.

## Gardez un registre ordonné lorsque le vendeur répond
Si vous recevez des éclaircissements, enregistrez la réponse du vendeur avec sa date et l'annonce spécifique. Indiquez s'il confirme l'option existante ou propose un substitut. Par exemple, la confirmation que « le code C comprend le kit de montage » est différente d’une offre d’ajouter le kit séparément pour un montant supplémentaire. Mettre à jour les spécifications écrites si le changement proposé est accepté.

Une fois la transaction terminée, conservez l'option originale, le sommaire accepté et la preuve que vous avez utilisée pour approuver l'article d'entrepôt. Lorsque vous revenez sur la feuille de calcul plusieurs mois plus tard, vous pouvez voir un ordre d'option différent ou des traductions différentes. Votre dossier indiquera toujours ce que le vendeur a offert à l'époque et ce que vous avez réellement commandé. C'est la valeur pratique de garder le libellé du vendeur: il survit aux changements à la présentation assez longtemps pour répondre aux questions sur votre achat particulier.

Pour les pièces correspondantes, vérifiez la cohérence des options sur plus d'une liste. Un boîtier et sa sangle séparée peuvent tous deux être décrits comme verts tout en portant des noms de couleurs ou des largeurs de fixation différents. Demandez l'étiquette ou la mesure précise qui relie les deux. Si une finition assortie est essentielle, faites cette condition explicite avant de payer pour l'une ou l'autre partie. Deux étiquettes qui se traduisent par le même mot anglais peuvent toujours faire référence à des finitions distinctes dans le catalogue du vendeur.
