# CNShopper link import or manual order: deciding what to do when a listing fails
You paste a seller link into a shopping agent and the item does not appear as expected. Sometimes the source page has disappeared. Sometimes the page exists but the agent cannot capture an important option. Sometimes the wrong link was copied. A manual order is useful when a purchaser can identify a real offer from the information you provide. It does not repair an offer that you cannot identify yourself.

## Check whether the link is a product page
Open the original marketplace link and inspect its destination. Does it show one product with a seller and options? A search-results page, seller homepage, promotional album or social-media photograph can contain the item without identifying a purchasable listing. Copy the product page rather than the page that led you to it. Preserve the marketplace name and item identifier if visible.

Imagine saving a screenshot of a desk organiser from a seller's gallery. Tapping the shared address opens the shop's entire stationery collection. You can recognize the product in a picture, but the purchaser still needs to know which listing and option to buy. Find the individual organiser or ask the seller for its link. A manual note that says “third item in the picture” may become unusable when the seller changes the display order.

## Understand what a successful import should establish
CNShopper's ordering guide describes starting with a marketplace link and confirming the item, option, quantity and cost before purchase. Use that sequence to test the import. Match the seller, item identity, variant choices and price for the actual option you want. A page loading successfully is only the first result. If the cheapest option is an accessory while you want the complete product, the price beside the first picture does not settle the purchase.

Try making the complete selection before deciding that something is missing. A size list may depend on the colour you chose first. A bundle may expose another selector for its contents. After all fields are set, read the final summary together. If it faithfully describes your intended item, a normal link-based order provides a simpler record than re-entering the same information manually.

## Distinguish an import problem from a seller problem
Return to the seller page and check whether the combination exists there. If the seller offers green in medium but the imported page omits that option, you have an identifiable discrepancy to ask about. If the seller no longer lists green at all, a manual order cannot establish that the seller has one. Ask about availability before authorizing payment or selecting another colour.

For an edited listing, keep the date of your evidence. A screenshot from last month may explain what you were seeking but may no longer describe the current offer. Save the current seller page alongside the older reference and identify the difference. For example, “the older page displayed a detachable tray; today's option only names the organiser body.” A clear question about the tray is more useful than resubmitting an old link and hoping it restores the former bundle.

## Build a manual request from positive identifiers
If a manual or DIY purchase is offered for your case, state the seller URL, product name, exact original option text, intended colour, size, unit and quantity. Add the price as displayed for that selection and specify its currency. Include a screenshot of the selected option where it resolves ambiguity. The request should allow the purchaser to find the offer even if the translation of its title changes.

Separate instructions from questions. “Buy the 36-centimetre grey organiser with removable tray, quantity one, if the tray is included in this option” is a conditional instruction. “Can the seller confirm that the tray is included?” is the question that must be answered first. If the condition matters to you, state whether you want the purchase held until you receive an answer. Avoid choosing a cheaper option and writing the name of a different product in the notes.

## Keep substitutions under your control
A manual request sometimes becomes ambiguous when a seller cannot supply the exact selection. Decide in advance which differences are acceptable. Some buyers would accept a different outer carton but insist on the same dimensions. Others need an exact shade for a matching set. State the requirement and what the purchaser should do if it cannot be met.

An example is a pair of matching storage boxes. The blue shade shown in your reference matches an existing shelf, while a seller also offers teal. The two option pictures look alike on a phone but the seller names differ. If colour determines the purchase, write “please ask before replacing the selected blue with another shade.” Do not write “anything similar is fine” merely to complete the form unless that is truly your decision.

## Verify the commercial details before paying
For a manual selection, compare the confirmed product price, unit count and domestic delivery with the original seller offer. If the figure changes, identify why. It may reflect a higher-priced variant, a minimum order, shipping from the seller or a newer price. An explanation that aligns the order with the actual listing lets you make a purchasing decision. A guessed reason does not.

Consider a listed amount of 30 for a replacement lid and 110 for the complete container. If you request the full container, the difference is not an unexplained surcharge. Conversely, if the confirmed amount is 110 for a lid-only option, that discrepancy needs clarification. Use illustrative figures only to understand the distinction. Your actual order should retain the seller's current amount and currency, and the international parcel budget should remain separate from the purchase payment.

## Decide when to stop and look elsewhere
If neither the listing nor the seller can identify the requested option, pause rather than converting uncertainty into an order. A manual form can communicate an intention; it cannot supply missing evidence about availability, authorization to sell or exactly what is included. If you choose an alternative seller, begin a new comparison. Do not carry over the previous seller's size table, expected accessories or photographs as if they describe the replacement.

In some cases a direct source link returns after a seller updates the page or sends a corrected address. Recheck the new link against your requirements and decide whether link import now provides a complete offer. If an earlier manual request is still open, identify it and avoid telling two purchasers to buy the same unit. Confirm which request will proceed before paying twice or cancelling the wrong record.

## Carry the selection through warehouse review
Once the order is confirmed, keep your final specification with the order reference. At warehouse intake, use that specification to review the actual item. A photograph showing one grey organiser may establish its colour and general shape, while a view of the lid and tray laid out together may be necessary to confirm the bundle. Ask about the unresolved feature while the item is still accessible for inspection.

The practical test is whether your order can be read by someone who never saw the original shortlist. They should be able to name the seller, identify the product, reproduce the option, count the units and say what to do if a key feature is unavailable. When link import supplies that information, use it. When only a manual request can carry it accurately, give the purchaser a specification they can verify. The workflow should follow the quality of the offer you actually found.

If the original listing later begins importing correctly, check your purchase history before starting over. A manually submitted request and a new imported cart line can both refer to the same desired unit. Mark which request should proceed and resolve the other through the order's available controls.
