# Orientdig Grid

Production domain: https://orientdiggrid.com

Cloudflare Worker; build: `npm run build`; deploy: `npx wrangler deploy`. Cloudflare root directory: `orientdiggrid-com`. No database or storage bindings. Catalogue and detail photos from cnbuycha.com; public Weidian listing IDs supply real style images. Image search signatures are derived from the source catalogue.

Sitemap: /sitemap.xml (24 language product maps plus pages). Canonical host: orientdiggrid.com; www and HTTP redirect with 308.
