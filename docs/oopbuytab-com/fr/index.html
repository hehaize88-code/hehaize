FAQ
OOPBuy Tab est-il le site officiel d’OOPBuy ?+

OOPBuy Tab est un site indépendant de découverte de produits. L’inscription, les commandes et les paiements ont lieu sur oopbuy.com. Les liens d’achat comprennent un code d’invitation affilié ; aucune remise n’est promise.

D’où viennent les produits et les prix ?+

Les annonces, images, résultats de recherche et tris proviennent de CNBuyCha. Les prix sont affichés en USD dans toutes les langues. Confirmez le prix actuel, la disponibilité et la variante choisie dans OOPBuy.

Les photos des produits sont-elles des photos QC de l’entrepôt ?+

Les images affichées proviennent de CNBuyCha. Leur origine en tant que photos QC d’entrepôt n’a pas été vérifiée. Vérifiez les photos de votre propre commande dans OOPBuy avant de décider de l’expédier.
