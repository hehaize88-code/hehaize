Quelques points à connaître.

Des réponses claires sur le spreadsheet, les photos et les liens d’achat.

OOPBuy Tab est-il le site officiel d’OOPBuy ?+

OOPBuy Tab est un site indépendant de découverte de produits. L’inscription, les commandes et les paiements ont lieu sur oopbuy.com. Les liens d’achat comprennent un code d’invitation affilié ; aucune remise n’est promise.

D’où viennent les produits et les prix ?+

Les annonces, images, résultats de recherche et tris proviennent de CNBuyCha. Les prix sont affichés en USD dans toutes les langues. Confirmez le prix actuel, la disponibilité et la variante choisie dans OOPBuy.

Les photos des produits sont-elles des photos QC de l’entrepôt ?+

Les images affichées proviennent de CNBuyCha. Leur origine en tant que photos QC d’entrepôt n’a pas été vérifiée. Vérifiez les photos de votre propre commande dans OOPBuy avant de décider de l’expédier.

Le prix de l’article comprend-il la livraison ?+

Considérez le montant affiché comme un prix estimé de l’article. Vérifiez le transport intérieur, la livraison internationale, les services facultatifs et les frais applicables dans le paiement et le devis de colis actuels.

Comment fonctionnent les liens d’achat ?+

Le bouton d’une page produit ouvre son identifiant d’article Weidian d’origine dans OOPBuy. Le numéro du catalogue CNBuyCha est un identifiant distinct. Vérifiez l’annonce de destination avant de commander.

Puis-je rechercher avec une image ?+

La recherche par image n’est pas disponible dans cet aperçu. Vous pouvez rechercher par nom ou parcourir les catégories. Nous ne remplaçons pas une photo envoyée par des résultats sans rapport.
