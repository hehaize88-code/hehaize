# Mobile and image-search release — 2026-11-12

Mobile presentation retains all editorial content and adds accessible section toggles, full-content print support, and local paging for long lists. Native catalogue pages use the same mobile behavior as editorial routes. Desktop remains expanded.

Image search scans and SHA-256 verifies every immutable index shard in a worker, retaining only the best match per product. Matching secondary images link to the correct photo; style records link to the source style ID. An incomplete shard download is an error, never a successful partial search.

Validation: build:pages succeeds with 790 exported routes. Catalogue/detail tests (21), streaming integrity/coverage tests (5), and multilingual editorial integrity tests (4) pass. Numbered style colours translate in all supported languages without altering brands or seller identifiers. The standalone all-image maintenance builder passes its offline regression checks, including incremental products, immutable shard reuse, source identity, transient failure handling, transparency and Retry-After. Temporary noindex /qa pages are removed from the final release.

Browser verification: 480 route variants at a 320 × 740 CSS-pixel frame; 474 loaded on the first pass and six transient blank loads passed individual retry. Every default view was ≤ 5 screens with no horizontal document overflow. A 390 × 844 pass covered 342 loaded routes (maximum 4.1 screens). The article archive retains all 29 cards while paging six at a time. Expand all revealed all eight sections of the insurance article. A real jacket secondary-photo search opened ?photo=2; seller deep links show the exact seller photo.

Final image coverage: all 3,467 products; 97,172 indexed product/image records, representing 90,610 unique image URLs. Coverage consists of 13,544 gallery records, 69,183 style records and 14,445 seller-photo records. All 90,738 discovered URLs were attempted. No image or style page remains unattempted.

All 139 shards pass SHA-256, byte-size and record-count verification, preserving the existing 55 gallery URLs. Total shard data is 52,844,246 bytes (approximately 9,725,072 bytes with gzip level 6). Real secondary-gallery, final-style and seller-photo fixtures each rank first when the production streaming search scans the complete index.
