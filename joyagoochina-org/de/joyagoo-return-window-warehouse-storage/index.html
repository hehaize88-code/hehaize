01

Rückgabefrist prüfen, bevor Sie die Lagerung planen

Eine erlaubte Lagerdauer ist keine Rückgabefrist. Die Einkaufsanleitung von Joyagoo beschreibt einen Zeitraum für Rückgabe- oder Umtauschanfragen nach der QC; die Lagerung ist eine gesonderte Leistung. Prüfen Sie die Frist und die verfügbare Rückgabefunktion Ihrer konkreten Bestellung, sobald die Fotos vorliegen. Speichern Sie gewählte Variante, QC-Bilder und Begründung. Warten Sie mit der Prüfung eines möglicherweise zurückzusendenden Artikels nicht, bis alle übrigen Einkäufe eingetroffen sind.

Öffnen Sie für eine Erstattungsanfrage die betreffende Bestellung, prüfen Sie die Rückgabe- oder Umtauschoption und senden Sie eine konkrete Erklärung mit Nachweisen. Klären Sie Zustimmung des Verkäufers, Rücktransportkosten und das Zielkonto einer Erstattung, bevor Sie den Vorgang als abgeschlossen betrachten. Bewahren Sie Verpackung und Etiketten bis zur Entscheidung auf. Sind Frist oder Funktion unklar, fragen Sie im selben Bestellverlauf nach. Zusätzliche Fotos oder eine verlängerte Lagerdauer verlängern die Rückgabemöglichkeit nicht automatisch.
