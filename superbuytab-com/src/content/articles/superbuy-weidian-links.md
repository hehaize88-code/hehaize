To buy from Weidian with Superbuy, start with the original product URL, open it in Superbuy's purchasing flow and verify the seller, colour, size and quantity. Pay only after the order details are clear; review the available warehouse evidence before arranging international delivery.

This guide follows the handoff from a recommendation page to an order. If the original listing is unavailable, the wrong item opens or product details fail to load, use the [link troubleshooting guide](/articles/superbuy-links-not-working/) first. A working URL still requires confirmation of availability, seller conditions and shipping eligibility.

## Find the original marketplace link

On SuperbuyTab, open a product and look for its original listing. The source is supplied by CnBuyCha; we do not create a replacement listing or take your payment. The Superbuy button uses the available original marketplace URL so you can review the product in Superbuy's purchasing flow.

A typical Weidian item address contains an `itemID` value. That value identifies the marketplace listing. It is not necessarily the same as the number used in our catalogue page address, and it should not be replaced with an internal catalogue ID.

For example, the user-supplied test link for this project contains the Weidian item ID `7831516792`. It is an example of link structure, not a recommendation or evidence of stock. When checking your own item, use its own source URL and verify the details shown by the marketplace and Superbuy.

## Understand the purchase link before using it

The Superbuy buying address contains a `url` parameter with the source listing encoded inside it. Encoding turns characters such as a question mark into a form that can travel safely inside another URL. Seeing `%3A` or `%2F` in that parameter does not mean the item ID has changed.

Our referral links also include partner code `ES7pVI`. This identifies the referral relationship. It does not specify your size, guarantee a discount or change the seller's return conditions. We may receive a commission when you use eligible links, as explained in the site disclosure.

Check the destination domain when moving from a recommendation site to a purchase page. The buying flow should be on Superbuy's official domain. You do not need to give this recommendation site your Superbuy password, payment details or order account access.

## Reconcile the listing and the order form

Read the item title and compare the product photographs, but give particular attention to the selectable options. A photograph may illustrate the entire listing while the default option refers to one particular version. If there are several variations, make a deliberate selection rather than accepting the first available value.

Use a three-column check before payment:

| Detail | Original listing | Superbuy order form |
| --- | --- | --- |
| Identity | Seller and marketplace item ID | Same intended listing |
| Variation | Exact colour or version label | Matching selected option |
| Size | Seller's measurement chart | Intended size option |
| Quantity | Units or minimum order requirement | Intended number of items |
| Price | Price for that variation | Current amount before payment |

Any unresolved difference belongs in a question to support, not in a hopeful assumption. Save the original URL so the person handling the enquiry can see the same product you are discussing.

## Handle unclear or unavailable listings

If a source page will not open or Superbuy cannot display the product correctly, avoid changing digits in the URL to make a different page load. You could accidentally purchase a different item with a similar photograph. Return to the source listing and confirm that the link itself is still valid.

A useful enquiry contains the original link, the option you want, the quantity and a short description of the problem. If you have a screenshot of the intended option, include it through the appropriate official support channel. Ask whether the item can be purchased and what information is needed to proceed.

Do not infer stock from the presence of a catalogue card. An independent collection can still display a product while a seller changes a variation or removes an offer. A live source feed improves discovery, but the purchasing screen and seller confirmation remain the places to resolve availability for your specific order.

## Write instructions that can be checked

An instruction should describe an observable outcome. “One black bag, small size, silver hardware, option labelled X” gives a reviewer something concrete to compare. “Best quality please” does not identify a variation or establish a standard that can be verified from the order.

For clothing, distinguish between the size you select and a measurement you want confirmed. If the seller's chart is unclear, ask before purchase. If you later need the received garment measured, specify the measuring method and reference points instead of asking only whether it is “true to size.”

Keep your instructions consistent with the selected options. A note requesting size L beside a form set to size M creates ambiguity. Resolve that conflict before payment; do not assume the note will silently override the order fields.

## Keep purchasing and international delivery separate

Superbuy's published shopping-agent workflow separates buying the product from sending a warehouse parcel overseas. The amount shown while purchasing the item is therefore not a reliable substitute for the complete delivery budget.

Record the item amount and domestic delivery separately from your international shipping allowance. If the item is heavy, bulky, fragile or subject to a shipping restriction, investigate its delivery options before buying. An attractive seller price does not help if the available delivery arrangement does not fit your requirements.

For a budget you can update as information becomes available, read the [fees guide](/articles/superbuy-fees/). For the inputs behind a shipping estimate, use the [calculator guide](/articles/superbuy-shipping-calculator/).

## Match the received item to the order you placed

Once warehouse evidence is available, compare it with your recorded option rather than with a general promotional picture. Check the quantity and labels first. Then examine the feature that distinguishes your chosen version from the alternatives.

If the evidence is unclear, request a specific view or measurement. If it shows a mismatch, contact the agent through the relevant order and explain the difference with references. Avoid submitting the item for international shipping while you are still deciding whether it is the correct order.

Do not use photographs to make claims they cannot support. A visible label can help identify an option, but a photograph alone does not establish long-term durability, electrical performance or authenticity. For expensive or technically demanding products, decide what additional evidence you require before purchasing.

## Keep a compact purchase record

Your record can be as simple as the original URL, selected option, order reference, important messages and the decision after warehouse review. Keep the record private; there is no need to post account information publicly to ask a general buying question.

This record also helps distinguish an item issue from a shipping issue. A wrong variation should be discussed against the purchasing order. A parcel tracking problem should be discussed against the parcel record. Using the right reference reduces the chance of support investigating the wrong stage.

When you return to the [live spreadsheet](/spreadsheet/), treat the next find as a new decision. Reusing a familiar seller or product photograph is not a reason to skip the option check. A careful handoff takes little time and preserves the details that matter most.
