Si un enlace Superbuy no está funcionando, comience con la lista original del mercado. Compruebe si se abre, si el artículo todavía está disponible y si la dirección identifica un producto en lugar de una tienda o un resultado de búsqueda. Luego pega la URL del producto en Superbuy y compara el vendedor, opción seleccionada y cantidad antes de ordenar.

Un convertidor de enlace puede cambiar un formato de URL; no puede restaurar un elemento eliminado, crear stock o eliminar una restricción de compra. Esta guía separa esos problemas para que pueda evitar repetidamente intentar el mismo enlace roto. SuperbuyTab es un catálogo y guía independientes, y no puede aprobar un pedido o cambiar la lista de vendedores.

No asumo que todas las pantallas de error significan la misma cosa. Un listado no disponible y una importación temporalmente incompleta necesitan respuestas diferentes. Escriba el mensaje exacto antes de cambiar algo; de lo contrario, puede perder la única pista que identifica dónde se detuvo el proceso.

## Recuperar la dirección original del producto

Comience desde la página donde encontró el elemento. Abrir su enlace de listado original si uno está disponible. Un mensaje copiado puede contener una frase promocional, una instrucción de aplicación y una URL juntos. Utilice la dirección real del producto, a continuación, compruebe la página que abre. Mantenga el original sin editar en sus notas hasta que se haya verificado el reemplazo.

No elimine cada parámetro de consulta. Algunos parámetros identifican el elemento mismo. Weidian utiliza comúnmente un parámetro itemID, mientras que otros mercados usan diferentes identificadores o ponen un número de oferta en la ruta. Una dirección corta no es automáticamente una mejor dirección si acortarla elimina la identidad del producto.

Usted debe poder asociar la URL con un vendedor, un producto y una variación seleccionada. Si abre una página de inicio de la tienda, una página de búsqueda o una página genérica de inicio de sesión, aún no ha verificado el producto. Puede ser necesario iniciar sesión normal en el mercado para verlo; un convertidor no es un sustituto de ese acceso.

## Comprobar un enlace compartido de Taobao o Tmall

Los mensajes para compartir móviles pueden comportarse de manera diferente a una dirección completa del producto del navegador. Abra el artículo compartido en su mercado previsto, y obtenga la URL del producto de la página del artículo cuando sea posible. Compare el nombre y el vendedor antes de copiarlo en Superbuy. No seleccione un resultado de búsqueda no relacionado simplemente porque su fotografía parece similar.

Si Superbuy muestra la información del producto, trate eso como el comienzo de la verificación. Compruebe de nuevo los tamaños, colores y cantidades disponibles. Un enlace compartido puede llevar a la misma lista sin preservar la variante seleccionada de su amigo. Un precio inicial también puede referirse a una opción diferente de la que usted tiene la intención de comprar.

Mantenga las capturas de pantalla para su propio registro de pedido cuando un detalle importe, como un color etiquetado o una descripción del paquete. Te ayudan a explicar un desajuste más tarde, pero no reemplazan los términos actuales del vendedor. Evite enviar un pedido mientras la opción requerida siga siendo ambigua.

## Compruebe un enlace Weidian sin mezclar IDs

El número de producto interno de un catálogo y el identificador de listado del mercado sirven para diferentes fines. Si encuentras un artículo en SuperbuyTab, utiliza el enlace de compra o listado original suministrado. No construya una dirección Weidian usando el número al final de la URL de nuestra página de catálogo. Eso puede apuntar a un elemento diferente o ningún elemento en absoluto.

Después de abrir el original, compare el vendedor, la descripción del producto y las opciones disponibles con la página que lo introdujo. Una antigua hoja de cálculo puede sobrevivir a las existencias o la descripción del vendedor. Si el artículo ha cambiado materialmente, detenga y establezca lo que el vendedor está ofreciendo actualmente antes de utilizar una recomendación antigua.

## Consulta una oferta 1688 y sus reglas de cantidad

Para 1688, verifique que la dirección abre una oferta individual. Registrar si el precio mostrado se aplica a una sola pieza, un conjunto o un nivel de compra más grande. Un enlace que se carga correctamente todavía puede producir un pedido inválido cuando la cantidad no cumple los requisitos del vendedor. Ese es un problema de orden en lugar de un problema de formato URL.

No asuma que la edición de un campo de cantidad anula el mínimo. Pregunte si hay una muestra o un pedido más pequeño disponible y cuánto costaría antes de enviarla. Si el vendedor se niega, elija una cantidad permitida o una lista diferente. Nuestra [1688 guía de pedidos](/es/articles/superbuy-1688-guide/) explica los controles de cantidad, inspección y envío.

## Utilice un pedido manual sólo con información completa

La guía oficial para principiantes de Superbuy describe un formulario de pedido manual de agente de compras cuando la información del producto no puede ser capturada para las compras soportadas en el mercado. Si aparece ese formulario, suministre el enlace original del producto y los detalles del pedido solicitado. Confirmar el precio, variante, cantidad y cantidad de entrega nacional en lugar de adivinar los valores faltantes.

Un formulario manual no es una garantía de que un artículo sea comprable. Si la lista no está disponible, las mercancías están restringidas o los términos del vendedor no están claros, pida a Superbuy aclaraciones primero. Evite pagar dos veces por el mismo artículo mientras espera una consulta anterior o orden para ser resuelto.

Haga la pregunta específica: la página original se abre, la variante prevista es visible, pero falta un campo llamado en la página importada. Eso es más útil que decir sólo que todo está roto. Nunca envíe contraseñas de cuenta o detalles de tarjetas de pago con una solicitud de solución de problemas.

## Cuándo no ayuda convertir el enlace

Convertir un enlace no cambia el vendedor subyacente. No verifica de manera independiente la autenticidad, calidad de inspección, elegibilidad de las existencias o del envío. Si un sitio web ofrece un convertidor, revise el destino resultante antes de iniciar sesión o ingresar información de pago. Una página que se parece a Superbuy no es prueba de que pertenece a Superbuy.

Del mismo modo, cambiar una URL no puede resolver una advertencia de bienes prohibidos o una restricción de destino. Utilice el servicio oficial para determinar si el artículo puede ser pedido y enviado. No cambie la categoría de producto declarada simplemente para hacer desaparecer una advertencia; el paquete todavía contiene las mercancías originales.

## Terminar con un breve registro de verificación

Antes de realizar el pedido, guarde la dirección original, el nombre del vendedor, la opción exacta, la cantidad, la moneda mostrada y la fecha marcada. Añada la referencia de pedido Superbuy después de la compra. Esto le da una manera práctica de distinguir un problema de importación de un vendedor posterior, almacén o emisión de paquetes.

Una vez que el enlace esté funcionando, volver a la [catálogo de productos](/es/spreadsheet/) para comparar los elementos pertinentes, o revisar la [Desglose de los honorarios](/es/articles/superbuy-fees/) antes de pagar. Una página de producto de trabajo es un progreso útil, pero la compra completa aún incluye entrega nacional, decisiones de almacén y envío internacional.
