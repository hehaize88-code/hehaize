If a Superbuy link is not working, start with the original marketplace listing. Check whether it opens, whether the item is still available, and whether the address identifies a product rather than a shop or search result. Then paste that product URL into Superbuy and compare the seller, selected option and quantity before ordering.

A link converter can change a URL format; it cannot restore a deleted item, create stock or remove a purchasing restriction. This guide separates those problems so you can avoid repeatedly trying the same broken link. SuperbuyTab is an independent catalogue and guide, and cannot approve an order or change a seller's listing.

## Match the symptom to the next check

| What you see | What to check first | Useful next step |
| --- | --- | --- |
| A shop opens instead of an item | The shared address may identify the seller | Open the individual product and copy its address |
| The original page says unavailable | Stock, removal or seller changes | Ask about availability before attempting an order |
| The original works but import fails | The complete product URL and marketplace ID | Retry the original URL and use Superbuy support if needed |
| The wrong colour or size appears | The currently selected option | Select it again and check the final order summary |
| A quantity warning appears | Seller minimum quantity and pricing tier | Confirm the permitted quantity before paying |
| A delivery restriction appears | Item category and destination | Ask which compliant options are available |

Do not assume all error screens mean the same thing. An unavailable listing and a temporarily incomplete import need different responses. Write down the exact message before changing anything; otherwise you can lose the only clue that identifies where the process stopped.

## Recover the original product address

Start from the page where you found the item. Open its original-listing link if one is available. A copied message may contain a promotional sentence, an app instruction and a URL together. Use the actual product address, then check the page it opens. Keep the unedited original in your notes until the replacement has been verified.

Do not remove every query parameter. Some parameters identify the item itself. Weidian commonly uses an itemID parameter, while other marketplaces use different identifiers or put an offer number in the path. A short address is not automatically a better address if shortening it removes the product identity.

You should be able to associate the URL with a seller, a product and a selected variation. If it opens a shop homepage, a search page or a generic sign-in page, you have not yet verified the product. Normal marketplace sign-in may be necessary to view it; a converter is not a substitute for that access.

## Check a Taobao or Tmall share link

Mobile share messages can behave differently from a full browser product address. Open the shared item in its intended marketplace, then obtain the product URL from the item page where possible. Compare the name and seller before copying it into Superbuy. Do not select an unrelated search result merely because its photograph looks similar.

If Superbuy displays product information, treat that as the beginning of verification. Check available sizes, colours and quantities again. A shared link may lead to the same listing without preserving your friend's selected variant. A starting price can also refer to a different option from the one you intend to buy.

Keep screenshots for your own order record when a detail matters, such as a labelled colour or a bundle description. They help you explain a mismatch later, but they do not replace the seller's current terms. Avoid submitting an order while the required option is still ambiguous.

## Check a Weidian link without mixing up IDs

A catalogue's internal product number and the marketplace's listing identifier serve different purposes. If you find an item on SuperbuyTab, use its supplied buying or original-listing link. Do not construct a Weidian address using the number at the end of our catalogue page URL. That can point to a different item or no item at all.

After opening the original, compare the seller, product description and available options with the page that introduced it. An old spreadsheet entry can outlive a seller's stock or description. If the item has materially changed, stop and establish what the seller is currently offering before using an old recommendation.

For the complete purchase sequence, use our [Weidian buying guide](/articles/superbuy-weidian-links/). This troubleshooting page deals with finding and checking the correct link; the buying guide covers the later handoff, option selection and order record.

## Check an 1688 offer and its quantity rules

For 1688, verify that the address opens an individual offer. Record whether the displayed price applies to a single piece, a set or a larger purchase tier. A link that loads correctly can still produce an invalid order when the quantity does not meet the seller's requirements. That is an ordering issue rather than a URL-format problem.

Do not assume that editing a quantity field overrides the minimum. Ask whether a sample or smaller order is available and what it would cost before submitting it. If the seller refuses, choose a permitted quantity or a different listing. Our [1688 ordering guide](/articles/superbuy-1688-guide/) explains the checks for quantity, inspection and shipping.

## Use a manual order only with complete information

Superbuy's official beginner guide describes a manual shopping-agent order form when product information cannot be captured for supported marketplace purchases. If that form appears, supply the original product link and the requested order details. Confirm the price, variant, quantity and domestic delivery amount rather than guessing missing values.

A manual form is not a guarantee that an item is purchasable. If the listing is unavailable, the goods are restricted or the seller's terms are unclear, ask Superbuy for clarification first. Avoid paying twice for the same item while waiting for an earlier enquiry or order to be resolved.

Make the question specific: the original page opens, the intended variant is visible, but a named field is missing from the imported page. That is more useful than saying only that everything is broken. Never send account passwords or payment-card details with a troubleshooting request.

## Know when conversion will not help

Converting a link does not change the underlying seller. It does not independently verify authenticity, inspection quality, stock or shipping eligibility. If a website offers a converter, review the resulting destination before signing in or entering payment information. A page that looks similar to Superbuy is not proof that it belongs to Superbuy.

Likewise, changing a URL cannot resolve a prohibited-goods warning or a destination restriction. Use the official service to establish whether the item can be ordered and shipped. Do not change the declared product category simply to make a warning disappear; the parcel still contains the original goods.

## Finish with a short verification record

Before placing the order, save the original address, seller name, exact option, quantity, displayed currency and the date checked. Add the Superbuy order reference after purchase. This gives you a practical way to distinguish an import problem from a later seller, warehouse or parcel issue.

Once the link is working, return to the [product catalogue](/spreadsheet/) to compare relevant items, or review the [fee breakdown](/articles/superbuy-fees/) before paying. A working product page is useful progress, but the complete purchase still includes domestic delivery, warehouse decisions and international shipping.
