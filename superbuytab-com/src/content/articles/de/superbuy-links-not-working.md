Wenn ein Superbuy-Link nicht funktioniert, starten Sie mit der ursprünglichen Marktplatzliste. Prüfen Sie, ob es sich öffnet, ob das Element noch verfügbar ist und ob die Adresse ein Produkt anstelle eines Shop- oder Suchergebnisses identifiziert. Fügen Sie diese Produkt-URL in Superbuy und vergleichen Sie den Verkäufer, ausgewählte Option und Menge vor der Bestellung.

Ein Linkkonverter kann ein URL-Format ändern; er kann einen gelöschten Gegenstand nicht wiederherstellen, Vorrat erstellen oder eine Kaufbeschränkung entfernen. Dieser Leitfaden trennt diese Probleme, so dass Sie vermeiden können, wiederholt versuchen, die gleiche kaputte Verbindung. SuperbuyTab ist ein unabhängiger Katalog und Führer und kann keine Bestellung genehmigen oder die Auflistung eines Verkäufers ändern.

| --- | --- | --- |
| Ein Shop öffnet sich statt eines Artikels | Die gemeinsame Adresse kann den Verkäufer identifizieren | Öffnen Sie das einzelne Produkt und kopieren Sie seine Adresse |
| Die ursprüngliche Seite sagt nicht verfügbar | Bestands-, Umzugs- oder Verkäuferänderungen | Fragen Sie nach Verfügbarkeit vor dem Versuch einer Bestellung |

| Eine Lieferbeschränkung erscheint | Kategorie und Ziel | Fragen Sie, welche konformen Optionen verfügbar sind |

Nehmen Sie nicht an, dass alle Fehler-Bildschirme dasselbe bedeuten. Eine nicht verfügbare Auflistung und ein vorübergehend unvollständiger Import erfordern unterschiedliche Antworten. Schreiben Sie die genaue Nachricht auf, bevor Sie etwas ändern; sonst können Sie den einzigen Hinweis verlieren, der identifiziert, wo der Prozess aufgehört hat.

## Wiederherstellen der ursprünglichen Produktadresse

Beginnen Sie von der Seite, auf der Sie das Objekt gefunden haben. Öffnen Sie den Original-Listen-Link, wenn einer verfügbar ist. Eine kopierte Nachricht kann zusammen einen Werbesatz, eine App-Anweisung und eine URL enthalten. Verwenden Sie die tatsächliche Produktadresse und überprüfen Sie dann die geöffnete Seite. Bewahren Sie das uneditierte Original in Ihren Notizen auf, bis der Ersatz überprüft wurde.

Entfernen Sie nicht jeden Abfrageparameter. Einige Parameter identifizieren das Element selbst. Weidian verwendet häufig einen Parameter itemID, während andere Marktplätze verschiedene Identifikatoren verwenden oder eine Angebotsnummer in den Pfad setzen. Eine kurze Adresse ist nicht automatisch eine bessere Adresse, wenn sie die Produktidentität entfernt.

Sie sollten in der Lage sein, die URL mit einem Verkäufer, einem Produkt und einer ausgewählten Variante zu verknüpfen. Wenn es eine Shop-Homepage, eine Suchseite oder eine generische Anmeldeseite öffnet, haben Sie das Produkt noch nicht verifiziert. Ein normales Marktplatz-Anmelden kann notwendig sein, um es anzusehen; ein Konverter ist kein Ersatz für diesen Zugang.

## Einen geteilten Taobao- oder Tmall-Link prüfen

Mobile Share-Nachrichten können sich anders verhalten als eine Full-Browser-Produktadresse. Öffnen Sie das freigegebene Element in seinem beabsichtigten Marktplatz und holen Sie dann die Produkt-URL von der Artikelseite, wo möglich. Vergleichen Sie Namen und Verkäufer vor dem Kopieren in Superbuy. Wählen Sie kein nicht verwandtes Suchergebnis, nur weil sein Foto ähnlich aussieht.

Wenn Superbuy Produktinformationen zeigt, behandeln Sie dies als den Anfang der Überprüfung. Überprüfen Sie die verfügbaren Größen, Farben und Mengen erneut. Ein gemeinsamer Link kann zu der gleichen Liste führen, ohne die gewählte Variante Ihres Freundes zu bewahren. Ein Startpreis kann sich auch auf eine andere Option beziehen als die, die Sie kaufen wollen.

Halten Sie Screenshots für Ihren eigenen Auftragseintrag, wenn ein Detail wichtig ist, wie z.B. eine beschriftete Farbe oder eine Bundle-Beschreibung. Sie helfen Ihnen, eine Fehlanpassung später zu erklären, aber sie ersetzen nicht die aktuellen Bedingungen des Verkäufers. Vermeiden Sie das Absenden einer Bestellung, während die erforderliche Option noch zweideutig ist.

## Überprüfen Sie einen Weidian-Link, ohne IDs zu vermischen

Die interne Produktnummer eines Katalogs und die Kennung des Marktplatzes dienen unterschiedlichen Zwecken. Wenn Sie einen Artikel auf SuperbuyTab finden, verwenden Sie den mitgelieferten Kauf-oder Original-Listen-Link. Konstruieren Sie keine Weidian-Adresse mit der Nummer am Ende unserer Katalogseite URL. Das kann auf einen anderen Punkt oder gar keinen Punkt zeigen.

Nach dem Öffnen des Originals, vergleichen Sie den Verkäufer, Produktbeschreibung und verfügbare Optionen mit der Seite, die es eingeführt. Ein alter Tabelleneintrag kann den Bestand oder die Beschreibung eines Verkäufers überdauern. Wenn der Artikel sich wesentlich geändert hat, stoppt und stellt fest, was der Verkäufer derzeit anbietet, bevor er eine alte Empfehlung verwendet.

## Überprüfen Sie ein Angebot von 1688 und seine Mengenregeln

Überprüfen Sie für 1688, ob die Adresse ein individuelles Angebot öffnet. Aufzeichnen, ob der angezeigte Preis für ein einzelnes Stück, ein Set oder eine größere Einkaufsebene gilt. Ein Link, der korrekt geladen wird, kann immer noch eine ungültige Bestellung erzeugen, wenn die Menge den Anforderungen des Verkäufers nicht entspricht. Das ist eher ein Bestellproblem als ein Problem im URL-Format.

Nehmen Sie nicht an, dass das Bearbeiten eines Mengenfeldes das Minimum überschreibt. Fragen Sie, ob eine Probe oder kleinere Bestellung verfügbar ist und was es kosten würde, bevor Sie sie einreichen. Wenn der Verkäufer weigert sich, wählen Sie eine zulässige Menge oder eine andere Auflistung. ## Verwenden Sie eine manuelle Bestellung nur mit vollständigen Informationen

Superbuy's offizieller Einsteiger-Guide beschreibt ein manuelles Einkaufs-Agenten-Bestellformular, wenn Produktinformationen für unterstützte Marktkäufe nicht erfasst werden können. Falls dieses Formular erscheint, geben Sie den ursprünglichen Produktlink und die angeforderten Bestelldetails an. Bestätigen Sie den Preis, die Variante, die Menge und die inländische Liefermenge anstatt fehlende Werte zu erraten.

Eine manuelle Form ist keine Garantie dafür, dass ein Artikel verkäuflich ist. Wenn die Auflistung nicht verfügbar ist, werden die Waren eingeschränkt oder die Bedingungen des Verkäufers unklar sind, fragen Sie Superbuy zuerst um Klärung. Vermeiden Sie die Zahlung zweimal für den gleichen Artikel, während warten auf eine frühere Anfrage oder Bestellung gelöst werden.

Stellen Sie die Frage spezifisch: Die Originalseite öffnet sich, die beabsichtigte Variante ist sichtbar, aber ein benanntes Feld fehlt auf der importierten Seite. Das ist nützlicher, als nur zu sagen, dass alles kaputt ist. Senden Sie niemals Kontopassworte oder Zahlungskartendetails mit einer Fehlerbehebungsanfrage.

## Wann eine Linkumwandlung nicht hilft

Die Umwandlung eines Links ändert nichts an dem zugrunde liegenden Verkäufer. Es überprüft nicht unabhängig Authentizität, Inspektionsqualität, Lager- oder Versandfähigkeit. Wenn eine Website einen Konverter anbietet, überprüfen Sie das resultierende Ziel vor der Anmeldung oder Eingabe von Zahlungsinformationen. Eine Seite, die ähnlich wie Superbuy aussieht, ist kein Beweis dafür, dass sie zu Superbuy gehört.

Ebenso kann das Ändern einer URL eine verbotene Warenwarnung oder eine Zielbeschränkung nicht auflösen. Nutzen Sie den offiziellen Dienst, um festzustellen, ob der Artikel bestellt und versendet werden kann. Ändern Sie nicht die deklarierte Produktkategorie einfach, um eine Warnung verschwinden zu lassen; das Paket enthält immer noch die ursprüngliche Ware.

## Beenden Sie mit einem kurzen Prüfprotokoll

Speichern Sie vor der Bestellung die ursprüngliche Adresse, den Namen des Verkäufers, die genaue Option, die Menge, die angezeigte Währung und das überprüfte Datum. Nach dem Kauf die Superbuy-Bestellnummer hinzufügen. Dies gibt Ihnen einen praktischen Weg, um ein Importproblem von einem späteren Verkäufer, Lager oder Paket Problem zu unterscheiden.

Sobald der Link funktioniert, zurück zu den [Produktkatalog](/de/spreadsheet/) zum Vergleich relevanter Punkte oder zur Überprüfung der [Aufgliederung der Gebühren](/de/articles/superbuy-fees/) vor der Zahlung.
