# Editorial dictionary recovery

Primary run 45151418588 was launched from editorial-full-mt-20261123. Its 288 target dictionaries use the source JSON below editorial-translation/input. All validated dictionaries belong on editorial-full-mt-results-20261123 under dictionaries/{site}/{lang}.json. The results branch contains translation-current-run.json and a separate record for each repair under recovery-runs/{run_id}.json. Workflow run links use https://github.com/hehaize88-code/hehaize/actions/runs/{run_id}.

To recover a failed pair, check its original job logs, identify the affected source text, list only missing pairs in translation-recovery/targets.json on editorial-mt-recovery-20261123, and commit that change there. A push triggers this recovery workflow. An exact original paragraph key can receive a reviewed translation under translation-recovery/overrides/{site}/{language}.json. Every other entry uses the pinned MADLAD model. The inference script retries empty, repetitive-length or potentially truncated sentences individually with constrained decoding. Unresolved sentences fail visibly and can then be translated with a reviewed override. Each successful dictionary is checked for the exact full set of unique English keys and nonempty string values before committing to the isolated results branch. The branch does not deploy website content.
