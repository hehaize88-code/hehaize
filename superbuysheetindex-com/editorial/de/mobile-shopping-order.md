# Superbuy auf dem Smartphone: die gewählte Variante vor der Bestellung prüfen
Ein mobiler Bildschirm macht es einfach, ein Foto zu speichern und schwierig, den gesamten Kauf in einer Ansicht zu sehen. Das Bild, die gewählte Variante, die Menge und der Preis können auf separaten Panels angezeigt werden. Der App-Leitfaden von Superbuy beschreibt, wie man ein Produkt findet, seine Optionen auswählt und den Agenten bittet, es zu kaufen. Verwenden Sie diese Stufen als Checkpoints. Das Ziel ist es, Ihre gewünschte Auswahl den ganzen Weg vom Verkäufer-Listing bis zur bezahlten Bestellung zu tragen.

## Beginnen Sie mit einer wiederherstellbaren Produktreferenz
Bevor Sie Apps wechseln, speichern Sie den ursprünglichen Marketplace-Produktlink. Wenn ein Share-Blatt Werbetext um die Adresse herum enthält, behalten Sie nach Möglichkeit die zugrunde liegende Eintragsadresse bei. Notieren Sie sich kurz den Verkäufer und die Artikelnummer. Das gibt Ihnen einen Weg zurück, wenn das Öffnen eines Shopping-Links den aktiven Browser-Tab ändert oder wenn eine Marketplace-App auf ihren Startbildschirm zurückkehrt.

Ein Screenshot ist ein nützlicher Begleiter, besonders für ein unverwechselbares Muster. Es enthält selten alle Informationen, die zur Identifizierung eines aktiven Angebots erforderlich sind. Das gleiche Studiobild kann auf mehreren Produkten erscheinen oder von verschiedenen Verkäufern wiederverwendet werden. Ein gespeichertes Bild, das ein blaues Notizbuch zeigt, stellt nicht fest, in welchem Geschäft es angeboten wird, welches Papier darin ist oder ob das Foto nur das Cover zeigt. Speichern Sie zuerst den Link und dann das Bild.

## Überprüfen Sie die Übergabe an Superbuy
Der offizielle App-Leitfaden beschreibt die Suche vom Startbildschirm aus und das Erkennen bestimmter Produktlinks. Verwenden Sie die verfügbare Eingabemethode auf Ihrem Gerät. Wenn sich die Agentenseite öffnet, vergleichen Sie die Produkt- und Verkäuferinformationen mit dem, was Sie importieren wollten. Schließen Sie keine Übereinstimmung aus, nur weil das erste Bild vertraut aussieht.

Öffnet das Gerät eine Suchergebnisliste anstelle des exakten Produkts, behandeln Sie dies als neuen Identifizierungsschritt. Vergleichen Sie die ursprüngliche Artikelnummer, falls vorhanden, und prüfen Sie dann den Optionssatz und die Verkäuferdetails. Ein Suchergebnis bei einem anderen Verkäufer und einem niedrigeren angezeigten Preis ist eine gesonderte Kaufoption. Wenn Sie es immer noch möchten, überprüfen Sie es als neues Angebot, anstatt die frühere Auswahl in Ihren Notizen stillschweigend zu ersetzen.

## Lesen Sie das gesamte Optionsfenster
Öffnen Sie den Selektor und identifizieren Sie die gewünschten Abmessungen. Ein Produkt kann Farbe, Größe, Paketinhalt und Menge haben, die jeweils separat gesteuert werden. Einige Kombinationen sind möglicherweise nicht verfügbar, auch wenn das Farbfeld selbst auswählbar erscheint. Treffen Sie die vollständige Auswahl und suchen Sie dann nach der endgültigen Zusammenfassung. Scrollen Sie horizontal oder erweitern Sie Text, wenn die Benutzeroberfläche eine lange Optionsbeschriftung abkürzt.

Bei einem Angebot für Skizzenbücher gibt es zum Beispiel „schwarz, A5, punktkariert“ und „schwarz, A5, blanko“. Beide Vorschaubilder können denselben geschlossenen Einband zeigen. Wollen Sie unbedruckte Seiten, entscheidet das letzte Wort. Speichern Sie die vollständige Variantenbezeichnung. Eine Notiz wie „schwarzes Notizbuch“ lässt genau das Merkmal weg, das das Lager später prüfen soll.

## Überprüfen Sie die Einheit und die Anzahl, die Sie bestellen
Ein Mengenwähler zählt die Einheit, die durch die gewählte Option dargestellt wird. Wenn die Option ein Dreierpack angibt, kann die Einstellung der Menge auf zwei sechs physische Stücke bedeuten. Wenn sich der Preis auf ein Ersatzcover bezieht, kann das auf einem Lifestyle-Foto abgebildete Buch weggelassen werden. Lesen Sie nach der Auswahl die Einheitsbeschreibung und die Zwischensumme.

Eine anschauliche Überprüfung ist, "zwei Packungen, drei Stück pro Packung, sechs Stück erwartet" vor der Kasse zu schreiben. Vergleichen Sie diesen Wert mit der angezeigten Menge und der Optionenbeschreibung des Händlers. Wenn ein Bildschirm zwei Einheiten und ein anderer sechs Stücke beschreibt, können sie konsistent sein. Wenn Sie den Unterschied nicht selbst erklären können, bitten Sie den Agenten um Klärung, bevor Sie einen Kauf autorisieren. Versuchen Sie nicht, eine unbekannte Einheit zu beheben, indem Sie eine größere Zahl wählen und hoffen, dass der Verkäufer sie richtig interpretiert.

## Verwenden Sie den Warenkorb als endgültige Spezifikation
Nachdem Sie den Artikel hinzugefügt haben, öffnen Sie die Warenkorbzeile erneut. Überprüfen Sie die genaue Option, Menge, Verkäufer und aktuellen Preis. Ein zuvor gespeicherter Warenkorbartikel kann zwischen Sitzungen überleben und wie eine zweite Kopie des heutigen Artikels aussehen. Vergleichen Sie Daten oder Liniendetails, bevor Sie Mengen ändern. Wenn Sie eine alte Option durch eine neue ersetzen, können beide für die Zahlung ausgewählt bleiben.

Lies jede Anklage im Kontext. Der Einkaufsführer von Superbuy trennt den Kauf und die gegebenenfalls anfallende nationale Lieferung vom späteren internationalen Paketprozess. Speichern Sie die Währung und den Gesamtbetrag auf dem Kaufbildschirm. Wenn ein Katalog einen Preis für die Bequemlichkeit umrechnet, verwenden Sie diese Zahl für einen groben Vergleich und verwenden Sie den tatsächlichen Betrag für Ihre Zahlungsaufzeichnung. Eine mobile Benachrichtigung, die einen Kartenbetrag angibt, kann eine andere Währung verwenden und kann den ausgewählten Artikel nicht identifizieren.

## Schreiben Sie Notizen, die eine Entscheidung auflösen
Nennen Sie im Bestellhinweis eine Variante, die der Einkaufsagent prüfen kann. Schreiben Sie statt „wie abgebildet“ die Originalbezeichnung des Verkäufers und anschließend das wichtige Merkmal. Bei einem Skizzenbuch etwa: „Schwarzer Einband, A5, Blankoseiten. Bitte vor einem Austausch gegen punktkarierte Seiten nachfragen.“ Sind Personalisierungen möglich, übernehmen Sie Schreibweise sowie Groß- und Kleinschreibung sorgfältig und klären Sie offene Fragen vor dem Bezahlen.

Vermeiden Sie es, eine Notiz zu verwenden, um einer ausgewählten Option zu widersprechen, ohne zu überprüfen, ob der Verkäufer die Anfrage liefern kann. Die Auswahl des günstigeren Covers und der Vermerk „Komplettbuch bitte“ stellt nicht den Kauf des kompletten Sets dar. Wenn eine gewünschte Kombination im Live-Selektor fehlt, fragen Sie, ob sie verfügbar ist und was sie kostet. Speichern Sie die Antwort mit der Auftragsbestätigung.

## Folgen Sie der Bestellung ins Lager
Sobald die Zahlung abgeschlossen ist, speichern Sie die Superbuy-Bestellreferenz. Nutzen Sie für Fragen zu diesem Kauf die Bestellungsanfrage oder einen anderen angezeigten Kontaktweg. Eine Frage zu einer nicht verfügbaren Farbe gehört zum Einkaufsdatensatz, ein Versandangebot für ein konfektioniertes Paket, das vom Lager an den Kunden versendet wird, gehört später in den Prozess. Die Bezeichnung der Phase hilft der Person, die antwortet, zu verstehen, welche Aktion Sie erwarten.

Wenn der Gegenstand auf Lager ist, weist dich der offizielle Leitfaden auf Mein Lager hin. Öffne deine Notiz neben den Lagerbildern erneut. Überprüfen Sie, was sichtbar ist: ein geschlossener schwarzer Einband kann zwar der Farbe entsprechen, aber nicht dem Seitenlinial. Wenn der Innenraum wichtig ist, fordern Sie eine Ansicht an, die das relevante Merkmal zeigt, und überprüfen Sie die verfügbaren Inspektionsoptionen für diesen Artikel. Bewahren Sie die Artikelnummer in der Anfrage auf, damit ein Foto eines ähnlichen Notizbuchs nicht versehentlich für Ihre Entscheidung verwendet werden kann.

## Erholen Sie sich ruhig, wenn ein App-Wechsel Ihren Platz verliert
Wenn die App während des Bezahlvorgangs oder der Zahlung geschlossen wird, überprüfen Sie die Bestell- und Zahlungsdatensätze, bevor Sie die Aktion wiederholen. Ein Wiederöffnen des Checkout-Bildschirms zu Beginn stellt nicht fest, ob die Zahlung erfolgreich war. Suchen Sie nach der Bestellreferenz, dem Betrag, der Währung und dem letzten Zahlungsstatus. Wenn sie nicht einverstanden sind, verwenden Sie den offiziellen Support-Kanal mit diesen Details. Vermeiden Sie es, eine zweite Bestellung zu erstellen, nur um zu sehen, ob die erste existiert hat.

Schließen Sie ab, indem Sie eine kompakte mobile Aufzeichnung führen: Verkäuferlink, vollständige Option, Einheit und Menge, bezahlte Bestellreferenz und die Funktion, die bei der Aufnahme geprüft werden muss. Sobald Sie diese Felder haben, wird das Wechseln von Geräten oder das erneute Öffnen eines Warenkorbs überschaubar. Sie können genau erklären, was Sie beauftragt haben, Ihren eigenen Lagerartikel erkennen und die Fracht als neue Entscheidung behandeln, wenn der Artikel fertig ist. Diese Kontinuität ist wertvoller als eine bestimmte Anordnung von Schaltflächen in einem App-Update.

Bei Käufen, die für jemand anderen getätigt wurden, senden Sie die letzte ausgewählte Option an diese Person zurück, bevor Sie zur Kasse gehen, wenn die Auswahl mehrdeutig war. Bitten Sie ihn, das genaue Attribut zu bestätigen, um das es sich handelt, wie z. B. Maßstab, Ärmellänge oder enthaltenes Zubehör. Eine Antwort, die eine klare schriftliche Spezifikation genehmigt, ist später einfacher zu verwenden als ein Daumen hoch, das an ein allgemeines Produktfoto angehängt ist. Speichern Sie die endgültige Bestätigung neben dem ursprünglichen Auftragsdatensatz.
