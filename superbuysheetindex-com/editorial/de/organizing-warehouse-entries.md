# Superbuy-Lagereinträge vor dem Zusammenstellen eines Pakets ordnen
Eine Lagerliste beginnt als eine Reihe von Eingängen, wird dann allmählich zu einer Reihe von Entscheidungen. Eine Jacke ist fertig, eine andere muss gemessen werden, ein Geschenk muss seine Schachtel behalten und ein Ersatz für eine ältere Bestellung ist angekommen. Wenn Sie jeden sichtbaren Eintrag auswählen, können diese Entscheidungen miteinander vermischt werden. Organisieren Sie die Einträge nach dem, was Sie tatsächlich versenden können.

## Behalten Sie die Lagerreferenz als Anker
Starten Sie für jeden relevanten Lagerdatensatz zu einem einzelnen Artikel eine Zeile. Kopieren Sie die angezeigte Referenz, den zugehörigen Einkaufs- oder Weiterleitungsdatensatz und eine Beschreibung, die Sie später erkennen können. Ein übersetzter Produktname kann mehrdeutig sein. Eine Referenz in Kombination mit einer genauen Beschreibung, wie z. B. „Navy Medium, plain cuffs“, hilft Ihnen, ein Gerät von einem ähnlichen Artikel zu unterscheiden, der einige Tage zuvor gekauft wurde.

Lassen Sie den Verkäufer nicht den einzigen Schlüssel in Ihrem Datensatz bestellen. Eine Verkäuferauftrag kann mehrere Lagerdatensätze für einzelne Artikel erzeugen. Ein Versandpaket kann Waren aus mehr als einem Einkauf enthalten. Ein Ersatz kann dem Original so ähnlich sein, dass beide Titel identisch erscheinen. Behalten Sie ein separates Feld für das Ereignis, das die Einträge verknüpft, wie z. B. „Ersatz für den ursprünglichen Eintrag“ oder „zweite Einheit aus derselben Bestellung“, anstatt beide Waren umzubenennen, als ob sie eine wären.

## Erfassen Sie eine Entscheidung, eine ungelöste Frage und einen Eigentümer
Geben Sie jedem Eintrag einen praktischen Zustand. Nützliche Beispiele sind Versandbereit, wartet auf eine Messung, wartet auf Verkäuferinformationen, Rückgabe in Diskussion und absichtlich für einen anderen Artikel gehalten. Dies sind Ihre privaten Arbeitsnotizen; verwenden Sie den tatsächlichen Plattformstatus separat. Der Punkt ist, zu notieren, was Sie persönlich benötigen, bevor Sie diesen Artikel in ein Paket geben, das vom Lager zum Kunden versendet wird.

Nennen Sie für jede offene Frage, wer sie beantworten kann. Der Händler weiß möglicherweise, ob ein Zubehör zu einem bestimmten Bundle gehört. Das Lagerpersonal kann möglicherweise zeigen, ob dieses Zubehör physisch vorhanden ist. Sie können entscheiden, ob eine kleine kosmetische Markierung akzeptabel ist. Wenn in einer Zeile lediglich „Check“ steht, weiß niemand, durch welche Aktion sie geschlossen wird. Ersetzen Sie dieses Wort durch „Warte auf ein Foto des Innenetiketts“ oder „Vergleiche die Breite mit meiner eigenen Jacke“.

## Arbeiten mit einer gemischten Bestellung
Stellen Sie sich vier Einträge vor. Das erste ist ein marineblaues Hemd, dessen Größenetikett und Maße Sie akzeptiert haben. Das zweite ist ein weiteres marineblaues Hemd, diesmal in der größeren Größe für jemand anderen bestellt. Das Etikett ist unleserlich. Der dritte ist ein Becher mit einem zerbrechlichen Griff. Das vierte ist ein Buch, das Sie in seinem ursprünglichen Schuber aufbewahren möchten. Vier lagernde Einträge machen nicht automatisch vier versandbereite Einträge aus.

Markieren Sie das erste Hemd fertig. Halten Sie die zweite zur Identifizierung. Notieren Sie für den Becher den aktuellen Zustand und den Verpackungsschutz, den Sie benötigen, bevor er reist. Markieren Sie das Buch fertig unter Beibehaltung der Schutzhülle. So bleibt Ihnen nur noch ein Artikel zur Prüfung und zwei artikelspezifische Verpackungsanweisungen. Diese Ergebnisse sind viel informativer als eine Liste, in der alles „angekommen“ heißt.

## Restriktionen finden, bevor Sie Waren gruppieren
Überprüfen Sie die aktuellen Versandoptionen entsprechend dem Inhalt und dem Zielort, bevor Sie davon ausgehen, dass alles zusammen reisen sollte. Ein Gegenstand mit einer Batterie, einer zerbrechlichen Form oder ungewöhnlichen Abmessungen kann die nutzbare Routenliste verändern. Identifizieren Sie diese Eigenschaften anhand der tatsächlichen Artikelinformationen. Eine vage Katalogkategorie wie Zubehör bietet selten genügend Details, um die Versandberechtigung festzulegen.

Nutzen Sie mögliche Gruppen für die Planung. Eine Gruppe könnte normale Kleidung enthalten, die jetzt fertig ist; eine andere könnte den zerbrechlichen Gegenstand enthalten, dessen Verpackung zur Diskussion steht. Notieren Sie, welche Artikel und Verpackungsannahmen in jede Schätzung einfließen. Wenn eine Route verschwindet, nachdem Sie einen bestimmten Eintrag hinzugefügt haben, untersuchen Sie diese Änderung, bevor Sie die Frachtsummen vergleichen. Das Hinzufügen eines neuen Elements garantiert nicht, dass die ursprünglichen Routen- und Servicebedingungen unverändert überleben.

## Zeiterfassung auf Elementebene
Überprüfen Sie die aktuellen Speicherinformationen für jeden Eintrag in Ihrem Konto. Ankunft, Aufnahme und die Frist, die für diesen bestimmten Eintrag angezeigt wird, sind für Sie nützlicher als das Datum, an dem Sie das Produkt zum ersten Mal online gefunden haben. Ein älterer Artikel kann sich einem Entscheidungspunkt nähern, während ein neu auf Lager befindlicher Artikel desselben Verkäufers mehr Zeit zur Verfügung hat. Ein einzelnes Datum, das dem geplanten Paket beigefügt ist, verbirgt diesen Unterschied.

Wenn ein Verkäuferproblem noch offen ist, zeichnen Sie seine eigene Aktionsfrist unabhängig auf. Ein Lagergutschein und eine Verkäuferrückgabemöglichkeit beantworten unterschiedliche Fragen. Das Warten auf eine weitere Bestellung, um die Fracht zu konsolidieren, kann für einen bestätigten Artikel vernünftig und für einen Artikel mit einem ungelösten Fehler unklug sein. Lesen Sie die für Ihren Einkauf geltenden Bedingungen, bevor Sie sich von einem geplanten Versanddatum eine nicht damit zusammenhängende Rücksendeentscheidung leiten lassen.

## Vermeidung von Fehlern bei identischen Waren
Verwenden Sie eine konsistente Reihenfolge für ähnliche Einheiten. Vergleichen Sie die erste Notiz mit den Anweisungen für den Kauf, die entsprechende Lagerreferenz und deren Fotos miteinander. Beende diese Übereinstimmung, bevor du den nächsten fast identischen Gegenstand öffnest. Wenn einem Foto ein nützliches Merkmal fehlt, schreibe genau auf, welche Beweise fehlen. Zwei Kleidungsstücke mit der gleichen Frontgrafik benötigen möglicherweise unterschiedliche Etikettenansichten, um festzustellen, welches zu welchem Empfänger gehört.

Ein praktisches Beispiel sind zwei dunkle Sweatshirts, die in medium und large bestellt wurden. Ein Lagerbild kann ein markiertes großes Etikett zeigen, während das andere nur eine gefaltete Vorderseite zeigt. Beschriften Sie das gefaltete Medium nicht ausschließlich durch Eliminierung, wenn sich die andere Bestellung noch auf dem Transportweg befindet oder falsch verpackt sein könnte. Fragen Sie nach der identifizierenden Ansicht, die mit dem mehrdeutigen Eintrag verknüpft ist. Nach der Bestätigung notieren Sie, welches Gerät welches Etikett hat und das Datum dieser Prüfung.

## Artikelhinweise in Paketanweisungen übersetzen
Übertragen Sie vor der Absendung nur die Anweisungen, die für das gewählte Paket gelten. Eine Notiz, um eine Sammlersleeve zu behalten, gehört zum spezifischen Buch. Die Verstärkung eines Umkartons betrifft das gesamte Paket. Beschreiben Sie das Objekt und die Aktion zusammen, so dass eine Anweisung nicht versehentlich eine andere überschreibt, insbesondere wenn Sie einige Verpackungen entfernen, während andere Teile intakt bleiben.

Im Beispiel mit der Tasse und dem Buch steht „alle Verpackungen entfernen“ im Konflikt mit der Beibehaltung der Schutzhülle des Buches und kann den Schutz der Tasse entfernen. Eine nützlichere Anweisung identifiziert die äußeren Liefermaterialien, die entfernt werden können, die Einzelteile, die bleiben müssen, und die empfindliche Oberfläche, die geschützt werden muss. Fragen Sie, ob die gewünschte Behandlung verfügbar ist. Speichern Sie die akzeptierte Anweisung neben dem eventuell verpackten Paketdatensatz.

## Übereinstimmen der übermittelten Auswahl
Wenn Sie Waren aus My Warehouse zum Versand anmelden, vergleichen Sie die ausgewählten Lagerpositionen ein letztes Mal mit Ihrer Liste versandbereiter Artikel. Prüfen Sie Referenz, Variante, Stückzahl und Packanweisung. Ordnen Sie die Nummer des ausgehenden Pakets nach ihrer Vergabe den ausgewählten Positionen zu. Alle anderen behalten ihren eigenen Status. Dass drei Artikel im Paket liegen, beantwortet beispielsweise noch nicht die offene Messanfrage zum vierten.

Verwenden Sie nach dem Versand das Paket, das vom Lager zum Kundendatensatz für die internationale Sendungsverfolgung versendet wird. Bewahren Sie die ursprünglichen Lagerverbindungen auf, bis die Lieferung abgeschlossen ist. Wenn ein Paket mit drei Gegenständen ankommt, obwohl du vier erwartet hast, sollte deine Aufzeichnung dir sofort sagen, ob ein vierter Gegenstand tatsächlich ausgewählt oder absichtlich zurückgehalten wurde. Diese einzige Unterscheidung kann eine langwierige Suche durch Verkäuferhistorien, Carrier-Scans und fast identische Fotos ersparen.

Eine gute Lagerliste ist kurz genug, um gepflegt zu werden, und spezifisch genug, um die nächste Entscheidung zu beantworten. Wenn eine Zeile eine Referenz, physische Identität, Bereitschaft, offene Frage und eventuelles Paket enthält, kann sie einen Artikel vom Eingang bis zum Versand verfolgen, ohne die Details zu verlieren, die Sie dazu veranlasst haben, ihn auszuwählen.

Für Geschenke, die an verschiedene Empfänger gehen, fügen Sie die Zielgruppe zu jedem Eintrag hinzu, bevor Sie kombinierte Pakete vergleichen. Ein einmaliges günstiges Frachtangebot an Ihre Adresse sagt nichts über die Kosten der anschließenden Weiterverbreitung der Inhalte aus. Die Gruppierung nach beabsichtigtem Empfänger kann zunächst eine Versandoption offenlegen, die eine einfache Summe der Lagergewichte verbirgt.
